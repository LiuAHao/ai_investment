# 前后端联调修复 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 修复前后端默认端口不一致、组件直连接口和 token 键名不一致导致的联调失败问题。

**Architecture:** 后端默认监听端口统一到 `5001`，前端继续以 `VITE_API_BASE_URL` 或 `http://localhost:5001` 作为默认基址。历史研究页与研究工作台不再直接请求相对路径接口，而是统一复用 `apiClient.js` 中现有的 `getChatSessions()`，由同一处逻辑处理 token 与请求头。

**Tech Stack:** Python, Flask, React, Vite, Fetch API, pytest

```jsx
import React, { useState, useEffect } from 'react';
import { getAuthToken, getChatSessions } from '../../services/apiClient';

useEffect(() => {
  const loadSessions = async () => {
    if (!getAuthToken()) {
      setLoading(false);
      return;
    }
    try {
      const data = await getChatSessions();
      setSessions(data.sessions || []);
    } catch {
      setSessions([]);
    } finally {
      setLoading(false);
    }
  };
  loadSessions();
}, []);
```

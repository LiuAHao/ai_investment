# SSE 阶段渐进展示 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将研究页流程画布从“预铺完整阶段骨架”改为“根据后端 SSE 真实执行事件逐步浮现，并自动跟随当前阶段移动”的动态工作流展示。

**Architecture:** 保留现有 `PHASES`、`AGENTS`、`node -> phase` 映射作为展示顺序配置，但新增运行态可见集合和聚焦状态。SSE 事件只负责推进真实可见状态，轮询只负责最终态兜底，不伪造中间阶段；当前运行阶段通过 DOM ref 自动滚动到视口内，用户手动查看历史时暂停自动跟随。

**Tech Stack:** React, Vite, Vitest, React Testing Library, SSE EventSource, Playwright smoke tests

---

## 目标效果

- 提交分析后，页面只显示当前问题和“正在建立研究任务”，不显示完整阶段骨架。
- 收到 `task_started` 后显示工作流容器。
- 收到 `node_started` 后，对应阶段和节点淡入，节点状态为“运行中”。
- 收到 `node_completed` 后，对应节点改为“已完成”；如果之前没收到 started，也要补显示。
- 收到 `tool_started` 后显示“并行工具执行”阶段和工具卡片。
- 收到 `tool_completed` 后更新工具卡片；如果之前没收到 started，也要补一张工具卡。
- 收到 `evidence_added` 后显示证据池，并追加证据。
- 收到 `draft_created` 后显示报告草稿或报告区。
- 收到 `critic_completed` / `compliance_completed` 后显示校验区。
- 收到 `task_completed` 后补齐最终结果，完成归档，并滚动到报告区。
- 当前阶段出现或切换时，页面自动滚动到最新阶段。
- 用户手动向上滚动离开当前进度区域后，自动跟随暂停，并展示“回到当前进度”按钮。
- 已归档历史 turn 展示完整结果，不再受当前运行态 `visiblePhaseIds` 限制。

```jsx
const addUnique = (items, item) => {
  if (item == null || item === -1 || items.includes(item)) return items;
  return [...items, item];
};

const revealPhase = useCallback((phaseId) => {
  if (phaseId == null || phaseId === -1) return;
  setWorkflowStarted(true);
  setVisiblePhaseIds(prev => addUnique(prev, phaseId));
  setActivePhase(phaseId);
  setCurrentFocusId(`phase-${phaseId}`);
}, []);

const revealAgent = useCallback((agentId) => {
  if (!agentId) return;
  setVisibleAgentIds(prev => addUnique(prev, agentId));
  setCurrentFocusId(`agent-${agentId}`);
}, []);

const revealNode = useCallback((nodeName) => {
  const agentId = mapNodeToAgent(nodeName);
  const phaseId = mapNodeToPhase(nodeName);
  revealPhase(phaseId);
  revealAgent(agentId);
  return { agentId, phaseId };
}, [mapNodeToAgent, mapNodeToPhase, revealAgent, revealPhase]);
```

```jsx
const upsertTool = useCallback((toolData, patch = {}) => {
  const stepId = toolData?.step_id;
  const toolName = toolData?.tool_name || 'unknown';
  revealPhase(2);
  setWorkflowStarted(true);
  setCurrentFocusId(`tool-${stepId || toolName}`);
  setActiveTools(prev => {
    const exists = prev.some(t => (
      stepId ? t.stepId === stepId : t.name === toolName
    ));
    if (!exists) {
      return [
        ...prev,
        {
          stepId,
          name: toolName,
          status: 'running',
          desc: toolData?.description || toolName,
          logs: [],
          result: null,
          ...patch,
        },
      ];
    }
    return prev.map(t => (
      (stepId ? t.stepId === stepId : t.name === toolName)
        ? { ...t, ...patch }
        : t
    ));
  });
}, [revealPhase]);
```

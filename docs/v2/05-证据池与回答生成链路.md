# 05 - 证据池与回答生成链路

## 目标

本阶段目标是让最终答案从“模型汇总工具结果”升级为“基于证据池生成、可校验、可引用的投资研究结论”。

证据池是 V2 的核心之一。没有证据池，系统很难做到：

- 事实可追溯。
- 回答可校验。
- 风险可覆盖。
- 自动评测可执行。

## EvidenceItem 模型

```python
class EvidenceItem(BaseModel):
    evidence_id: str

    ]
    asset_id: Optional[str]

    source: str

```

## ToolResult 到 EvidenceItem

转换流程：

```text
ToolResult
  ↓
EvidenceAgent 清洗
  ↓
提取摘要、来源、时间、资产、置信度
  ↓
EvidenceItem
  ↓
Evidence Store
```

示例：

```text
cn_stock_history 返回近 90 日行情
  ↓
EvidenceItem:
  title = "宁德时代近 90 日价格与波动"
  summary = "区间涨跌、最新收盘、波动率、成交额变化"
  evidence_type = "market_data"
  source = "AKShare/东方财富"
```

## 证据排序

AnswerAgent 使用证据前应排序：

```text
综合分 = 相关性 * 0.35
      + 新鲜度 * 0.20
      + 置信度 * 0.20
      + 来源可靠性 * 0.15
      + 重要性 * 0.10
```

第一阶段可以简化为：

- 行情数据优先于普通新闻。
- 与资产直接相关的新闻优先。
- RAG 框架作为辅助。
- 用户偏好作为约束。

## 回答生成链路

```text
EvidenceItems
  ↓
AnswerDraftAgent
  ↓
CriticAgent
  ↓
ReviseAnswer
  ↓
ComplianceAgent
  ↓
AnswerComposer
```

## AnswerDraftAgent

职责：

- 只基于 evidence_items 生成初稿。
- 明确区分事实、推断和建议。
- 不输出最终合规免责声明，由后续节点统一处理。

Prompt 要点：

```text
你是投资研究草稿生成 Agent。
只能基于提供的证据生成分析。
如果证据不足，请明确写出缺失项。
不要承诺收益，不要输出确定性买卖指令。
请区分：事实依据、推断、风险、可选操作。
```

## CriticAgent

检查：

- 是否有无证据结论。
- 是否遗漏主要风险。
- 是否数据过旧。
- 是否与用户风险偏好冲突。
- 是否情景分析过于单一。

输出：

```json
{
  "passed": false,
  "score": 0.68,
  "issues": ["缺少数据时效性说明"],
  "required_revisions": ["补充行情数据的时间范围和限制"],
  "missing_evidence": []
}
```

## ComplianceAgent

检查：

- 确定性收益。
- 诱导交易。
- 内幕消息。
- 规避风险提示。
- Prompt 注入。

高风险时：

- 修改答案。
- 或返回安全回答。

## 验收标准

- 最终答案包含证据依据。
- 最终答案包含风险和数据限制。
- Critic 能发现至少一类无证据结论。
- Compliance 能拦截“必涨、稳赚、满仓”等表达。
- 前端能展示证据摘要。

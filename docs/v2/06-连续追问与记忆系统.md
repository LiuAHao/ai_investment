# 06 - 连续追问与记忆系统

## 目标

本阶段目标是把系统从“单轮分析器”升级成“可连续追问的投资助手”。

连续追问能力是 V2 的产品核心。用户不应该每次都重新输入资产和背景，系统应能理解：

- “那”指代上一轮资产。
- “如果三个月呢”指投资周期变化。
- “和腾讯比呢”指新增比较对象。
- “风险最大的点是什么”指追问上一轮结论。

## 记忆类型

### 1. 会话记忆

记录当前 session 的研究上下文：

- 当前资产。
- 上一轮意图。
- 上一轮答案。
- 上一轮证据。
- 关键假设。
- 用户追问历史。

### 2. 用户偏好记忆

记录跨 session 的偏好：

- 风险偏好。
- 投资周期。
- 关注市场。
- 关注行业。
- 回答风格偏好。

### 3. 研究假设记忆

记录某个资产当前研究中的关键假设：

- 增长逻辑。
- 风险变量。
- 估值约束。
- 新闻催化。
- 宏观影响。

## 追问识别

RouterAgent 判断 `follow_up` 的信号：

- 代词：那、这个、它、这只、上面、刚才。
- 省略资产：只问“还能买吗”“风险呢”“三个月呢”。
- 变更条件：如果、换成、对比、长期、短期。
- 继续讨论：展开说说、为什么、依据是什么。

## 追问类型

### 1. 修改投资周期

```text
用户：如果持有三个月呢？
```

处理：

- 继承上一轮资产。
- 更新 user_horizon。
- 重新规划短中期行情、新闻、风险。

### 2. 修改风险偏好

```text
用户：如果我是保守型呢？
```

处理：

- 继承资产和证据。
- 更新风险偏好。
- 重新生成操作选项。

### 3. 追问依据

```text
用户：为什么你觉得风险偏高？
```

处理：

- 不必重新查工具。
- 从上一轮证据中提取对应依据。
- 如果证据不足，再补查。

### 4. 增加比较对象

```text
用户：和比亚迪比呢？
```

处理：

- 继承上一轮资产。
- 新增比亚迪。
- Planner 生成 compare plan。

### 5. 追问新闻影响

```text
用户：最近这个利空影响大吗？
```

处理：

- 查上一轮新闻证据。
- 必要时重新搜索新闻。
- 输出短期/中期影响。

## MemoryAgent 职责

### load_context

- 读取 research_contexts。
- 读取 chat_history。
- 读取 user_preferences。
- 读取上一轮 evidence。

### update_context

- 保存当前资产。
- 保存最终答案摘要。
- 保存证据 ID。
- 保存关键假设。
- 更新用户偏好。

## 关键假设提取

每次最终答案后，系统应提取：

```json
{
  "asset_id": "cn_stock:300750",
  "assumptions": [
    "短期走势受新能源车销量和电池价格影响",
    "估值水平对市场风险偏好敏感",
    "三个月周期内新闻催化和技术位置更重要"
  ]
}
```

这些假设用于后续追问。

## 验收标准

- 用户第二轮说“那三个月呢”，系统能继承上一轮资产。
- 用户说“和苹果比呢”，系统能新增比较对象。
- 用户问“依据是什么”，系统能引用上一轮证据。
- 用户修改风险偏好后，答案风格和操作选项会变化。
- 会话上下文保存到数据库。

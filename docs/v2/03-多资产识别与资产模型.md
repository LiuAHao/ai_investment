# 03 - 多资产识别与资产模型

## 目标

本阶段目标是建立统一资产模型，让系统从 A 股单资产扩展到：

- A 股股票
- 港股
- 美股
- 基金
- ETF
- 指数
- 宏观指标
- 行业和主题概念

统一资产模型是 V2 的基础。没有统一资产模型，Planner 无法稳定选择工具，连续追问也难以继承上下文。

## Asset 模型

```python
class Asset(BaseModel):
    asset_id: str
    asset_type: Literal[
        "cn_stock",
        "hk_stock",
        "us_stock",
        "fund",
        "etf",
        "index",
        "macro",
        "industry",
        "unknown",
    ]
    symbol: Optional[str]
    name: Optional[str]
    market: Optional[str]
    currency: Optional[str]
    exchange: Optional[str]
    confidence: float
    aliases: List[str] = []
    metadata: Dict[str, Any] = {}
```

## asset_id 规范

建议统一格式：

```text
cn_stock:300750
hk_stock:00700
us_stock:AAPL
fund:000001
etf:510300
index:000300
macro:CN_CPI
industry:新能源车
```

## 资产识别来源

### 1. 规则识别

适合显式代码：

- A 股：`300750`、`SZ300750`、`300750.SZ`
- 港股：`00700.HK`、`HK00700`
- 美股：`AAPL`、`TSLA`
- 基金：6 位基金代码，如 `000001`
- ETF：常见 6 位 ETF 代码，如 `510300`

### 2. 本地主数据

建议建立资产主数据文件：

```text
src/asset/data/
├── cn_stock_master.jsonl
├── hk_stock_master.jsonl
├── us_stock_master.jsonl
├── fund_master.jsonl
├── etf_master.jsonl
├── index_master.jsonl
└── macro_master.jsonl
```

单条格式：

```json
{
  "asset_id": "cn_stock:300750",
  "asset_type": "cn_stock",
  "symbol": "300750",
  "name": "宁德时代",
  "market": "CN",
  "exchange": "SZSE",
  "aliases": ["宁王", "CATL"],
  "currency": "CNY"
}
```

### 3. 在线补全

当本地无法识别时：

- 调用行情搜索。
- 调用搜索引擎。
- 返回候选项。

## 追问场景处理

如果用户输入：

```text
那如果持有三个月呢？
```

处理逻辑：

1. Router 判断为 `follow_up`。
2. AssetResolver 先查上一轮 `previous_assets`。
3. 如果上一轮只有一个资产，直接继承。
4. 如果上一轮有多个资产，结合用户问题判断是否继承全部。
5. 如果无法判断，返回 `need_user_clarification=true`。

## 歧义处理

示例：

```text
分析平安
```

可能候选：

- 中国平安 A 股
- 中国平安港股
- 平安银行
- 平安基金相关产品

策略：

- 如果用户上下文有市场偏好，优先该市场。
- 如果用户输入包含“银行”，优先平安银行。
- 如果置信度低于 0.7，前端提示用户选择。
- 不要在歧义过高时强行分析。

## 资产类型与工具映射

```text
cn_stock → A 股行情、A 股历史、技术指标、新闻、RAG
hk_stock → 港股行情、港股新闻、汇率、宏观
us_stock → 美股行情、美股新闻、美元利率、宏观
fund → 基金净值、持仓、回撤、费率、同类比较
etf → ETF 净值、跟踪指数、成交额、折溢价、持仓
index → 指数行情、成分股、宏观、市场情绪
macro → 宏观指标、政策新闻、历史趋势
industry → 行业新闻、行业指数、代表公司、RAG
```

## 验收标准

- “分析宁德时代”识别为 `cn_stock:300750`。
- “分析 AAPL”识别为 `us_stock:AAPL`。
- “沪深300 ETF 怎么看”识别 ETF 或指数相关资产。
- “000001 基金风险如何”能进入基金分析。
- “那三个月呢”能继承上一轮资产。
- 歧义资产能返回候选而不是强行生成结论。

# 10 - 阶段排期与验收清单

## 总体节奏

建议按 5 个里程碑推进：

```text
M1：V2 最小闭环
M2：证据与校验闭环
M3：多资产覆盖
M4：自动化评测
M5：工程化和前端工作台
```

## M1：V2 最小闭环

### 目标

在不破坏 V1 的情况下跑通 V2 查询链路。

### 开发任务

- 新增 `src/agent/v2` 目录。
- 新增 `state.py`。
- 新增 `schemas.py`。
- 新增 `router_agent.py`。
- 新增 `planner_agent.py`。
- 新增 `graph.py`。
- 新增 `src/api/agent_v2.py`。
- 注册 V2 API 蓝图。
- 复用 V1 DataAgent、NewsAgent、KnowledgeAgent、AnalysisAgent。

### 验收

- `/api/agent/v2/query` 可启动任务。
- `/api/agent/v2/status/{task_id}` 可查询状态。
- “分析宁德时代”能返回结果。
- “什么是市盈率”不强制调用行情。
- V1 原接口不受影响。

## M2：证据与校验闭环

### 目标

最终答案具备证据依据、Critic 校验和合规校验。

### 开发任务

- 新增 ToolResult。
- 新增 EvidenceItem。
- 新增 EvidenceAgent。
- 新增 Evidence Store 表。
- 新增 CriticAgent。
- 新增 ComplianceAgent。
- 新增结构化 InvestmentAnswer。

### 验收

- 回答包含证据依据。
- 回答包含风险和数据限制。
- 高风险词会被拦截。
- Critic 能指出证据不足。
- 工具失败时能降级回答。

## M3：多资产覆盖

### 目标

支持 A 股、基金、ETF、美股、港股、指数和宏观。

### 开发任务

- 新增 Asset 模型。
- 新增 AssetResolverAgent。
- 新增资产主数据。
- 新增 Tool Registry。
- 新增基金工具。
- 新增 ETF 工具。
- 新增美股工具。
- 新增港股工具。
- 新增宏观工具。

### 验收

- A 股名称识别正确。
- 美股 ticker 识别正确。
- 基金/ETF 代码识别正确。
- 歧义资产返回候选。
- Planner 根据资产类型选择工具。

## M4：自动化评测

### 目标

建立可以持续回归的自动化评测系统。

### 开发任务

- 新增 `src/eval`。
- 新增 eval datasets。
- 新增 RuleJudge。
- 新增 LLMJudge。
- 新增 EvalRunner。
- 新增 eval 数据表。
- 新增评测命令行入口。

### 验收

- 可运行核心评测集。
- 可运行安全评测集。
- 可输出分项得分。
- 可对比不同版本结果。
- 违规回答能被评测捕获。

## M5：工程化和前端工作台

### 目标

提升稳定性、观测能力和用户体验。

### 开发任务

- 引入 Celery/Redis。
- 新增后台任务状态。
- 新增 SSE 事件流。
- 前端新增研究工作台。
- 前端新增证据面板。
- 前端新增工具轨迹面板。
- 前端新增反馈入口。
- 前端新增评测面板。

### 验收

- 长任务稳定运行。
- 前端实时展示 Agent 过程。
- 用户可以连续追问。
- 用户可以提交反馈。
- 调试模式可以展示完整 trace。

## 推荐优先级

如果时间有限，优先做：

1. M1 V2 最小闭环。
2. M2 证据与合规。
3. M4 自动化评测。

原因：

- 这三项最能体现 AI Agent 工程能力。
- 多资产覆盖可以逐步扩展。
- 前端工作台可以作为展示增强，而不是核心依赖。

## 面试展示版本

最小可展示版本建议包含：

- RouterAgent。
- PlannerAgent。
- Tool Registry。
- Evidence Store。
- CriticAgent。
- ComplianceAgent。
- 自动评测 30 条样本。
- 一个多轮追问 demo。
- 一个 Prompt 注入防护 demo。

展示路径：

```text
用户问题
  ↓
Router 判断意图
  ↓
AssetResolver 识别资产
  ↓
Planner 生成计划
  ↓
Tool Registry 选择工具
  ↓
Evidence Store 收集证据
  ↓
Critic 校验
  ↓
Compliance 合规
  ↓
最终回答
  ↓
自动评测打分
```

这条链路能清晰体现工程能力，而不是陷入“投资准不准”的讨论。

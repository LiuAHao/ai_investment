# 09 - 前端研究工作台升级

## 目标

本阶段目标是把前端从“单次分析结果页面”升级为“连续追问式投资研究工作台”。

V2 前端重点展示：

- 多轮对话。
- 当前资产上下文。
- Agent 执行过程。
- 证据依据。
- 风险和情景分析。
- 用户反馈。
- 调试模式。

## 页面布局

推荐三栏布局：

```text
左侧：会话列表 / 研究主题
中间：连续对话区
右侧：资产上下文 / 证据面板 / 工具轨迹
```

顶部：

- 市场范围。
- 风险偏好。
- 投资周期。
- 使用模式 / 调试模式。

底部：

- 输入框。
- 快捷问题。
- 附加持仓入口。

## 使用模式

普通用户看到：

- 最终回答。
- 关键证据摘要。
- 风险提示。
- 情景分析。
- 操作选项。

不显示：

- 原始工具参数。
- 内部错误。
- Prompt。
- Agent 原始 JSON。

## 调试模式

调试模式显示：

- Router 输出。
- AssetResolver 输出。
- Planner 执行计划。
- ToolResult。
- EvidenceItem。
- CriticResult。
- ComplianceResult。
- Agent trace。

调试模式适合：

- 面试展示。
- 开发排查。
- 评测样本分析。

## SSE 事件流

替代轮询或作为增强：

```text
GET /api/agent/v2/events/{task_id}
```

事件类型：

```text
task_started
node_started
node_completed
tool_started
tool_completed
evidence_added
draft_created
critic_completed
compliance_completed
task_completed
task_failed
```

前端根据事件实时更新：

- 进度条。
- Agent 节点。
- 工具轨迹。
- 证据卡片。

## 资产上下文条

展示：

- 当前资产名称。
- 资产类型。
- 市场。
- 代码。
- 置信度。
- 投资周期。
- 风险偏好。

如果资产歧义：

- 显示候选列表。
- 用户点击选择后继续分析。

## 证据面板

每条证据展示：

- 标题。
- 摘要。
- 来源。
- 时间。
- 置信度。
- 利好/利空/中性。
- 数据限制。

证据分类：

- 行情。
- 新闻。
- 宏观。
- RAG。
- 基金/ETF。
- 用户偏好。

## 用户反馈

每个回答提供：

- 有用。
- 不准确。
- 风险提示不足。
- 不够具体。
- 工具数据有问题。
- 其他反馈。

反馈提交：

```text
POST /api/feedback
```

反馈用途：

- 加入反馈样本池。
- 自动分类。
- 后续转为评测样本。

## 评测面板

开发/调试页面展示：

- 最近评测运行。
- 总分趋势。
- 合规分趋势。
- 工具选择分。
- 多轮一致性分。
- 失败样本列表。

## 验收标准

- 用户可以连续追问。
- 前端能显示当前资产上下文。
- 前端能显示证据面板。
- 调试模式能显示 Agent 执行轨迹。
- 用户可以对回答提交反馈。
- 评测结果可以在开发页面查看。

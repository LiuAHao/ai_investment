## 推荐里程碑

### M1：V2 最小闭环

目标是让 V2 在不破坏 V1 的情况下跑通。

范围：

- 新增 V2 目录结构。
- 新增 V2 State / Schema。
- 新增 RouterAgent / PlannerAgent。
- 使用 LangGraph 编排。
- 复用 V1 的 DataAgent、NewsAgent、KnowledgeAgent、AnalysisAgent。
- 新增 `/api/agent/v2/query` 和 `/api/agent/v2/status`。

验收：

- A 股分析可以走 V2 链路。
- 概念问答不会强制调用行情工具。
- 简单追问能继承上一轮资产。

### M2：证据与校验闭环

目标是让答案不只是“模型说”，而是有证据、有校验、有合规边界。

范围：

- ToolResult 标准化。
- EvidenceItem 标准化。
- Evidence Store 入库。
- CriticAgent。
- ComplianceAgent。
- 结构化最终回答。

验收：

- 每个最终答案能列出证据依据。
- 高风险表达会被拦截或改写。
- 数据缺失时能明确说明限制。

### M3：多资产覆盖

目标是从 A 股扩展到基金、ETF、美股、港股、指数和宏观。

范围：

- Asset 统一模型。
- AssetResolverAgent。
- Tool Registry 支持资产类型匹配。
- 基金/ETF 工具适配。
- 港股/美股工具适配。
- 宏观工具适配。

验收：

- 不同资产类型能被正确识别。
- Planner 能根据资产类型选择合适工具。
- 同一个问题能比较多个资产。

### M4：自动化评测

目标是让系统质量可量化、可回归。

范围：

- 评测集。
- 规则评分。
- LLM Judge。
- 评测运行表。
- 评测报告。

验收：

- 可一键运行核心评测集。
- 能看到总分和分项分。
- 能对比 V1/V2 或不同 Prompt 版本。

### M5：工程化与前端体验

目标是提升长期可用性和展示效果。

范围：

- Celery/Redis 后台任务。
- SSE 或 WebSocket 事件流。
- 前端研究工作台。
- 证据面板。
- 工具轨迹面板。
- 评测面板。

验收：

- 长任务稳定运行。
- 前端能实时展示 Agent 过程。
- 调试模式和使用模式分离清晰。

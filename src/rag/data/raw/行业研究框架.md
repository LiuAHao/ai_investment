# 行业研究框架

## 适用范围

本手册提供主要行业的投资分析框架,包含各行业的核心指标、观察维度、周期判断方法与估值适用方法。供 Agent 在分析具体行业个股时,给出标准化、可溯源的框架性指引。行业景气判断属于阶段性观点,使用时需结合最新数据。

## 白酒行业

### 产业链地位与属性
- 市场容量大,龙头定价能力强,盈利水平高(毛利率高、现金流充裕)
- 兼具周期属性与消费属性:周期来源于居民收入、工业企业利润、社会流动性、经销商库存;消费属性来源于品牌与刚需
- 高中低端酒泾渭分明,适用不同分析框架与估值体系

### 核心跟踪指标
| 指标 | 说明 |
|------|------|
| 渠道库存水位 | 衡量经营健康度核心指标,经销商仓库积压程度直接反映供需失衡 |
| 批价(市场成交价) | 批价跌→回款弱;批价企稳→动销边际改善;批价与出厂价倒挂是风险信号 |
| 回款/打款情况 | 经销商打款积极度反映渠道信心 |
| 动销 | 终端实际销售,旺季备货数据 |
| 出厂价与提价周期 | 提价周期约2-3年,提价预期兑现时估值中枢上移 |
| 毛利率 | 高端白酒毛利率通常80%+ |
| ROE | 持续走高,现金流充裕 |

### 库存周期四阶段
1. **去库存(衰退)**:渠道压货、批价跌、回款弱
2. **库存底部(筑底)**:库存低位、批价企稳、动销边际改善
3. **补库存(复苏)**:旺季备货、批价回升、打款积极
4. **库存高位(过热)**:库存满、批价滞涨、后续承压

### 估值方法
- 高端酒:PE(盈利稳定),参考历史估值中枢
- 次高端/区域酒:PE + 成长性(PEG)
- 周期判断优先于估值:库存周期位置决定盈利方向,估值锚定需结合提价周期与库存周期

## 半导体行业

### 行业属性
- **周期 + 成长**双重属性:周期(价格、库存、产能、终端需求)+ 成长(新技术、国产替代)
- 投资核心在行业景气度:AI算力需求、供给缺口、国产化率提升

### 全球层跟踪指标(月度)
| 指标 | 频率 | 说明 |
|------|------|------|
| SIA 月度销售额 | 次月初公布 | 全球半导体销售景气 |
| 台积电月度营收 | 每月10日左右 | 代工景气领先指标 |
| SEMI 设备销售 | 季度末 | 产能扩张周期 |
| 芯片/存储价格 | 高频 | DRAM/NAND 现货价、HBM 价格 |
| 海外巨头季报指引 | 季度 | 英伟达/AMD/博通等需求指引 |

### 国内层跟踪指标
- 国产替代进度、设备采购、产能稼动率(利用率)
- 国内厂商订单、研发投入、技术节点突破

### 供需分析框架
- **供给侧**:长期看产能规划、资本开支;短期看设备采购、产能稼动率
- **需求侧**:长期看新科技新产品驱动;短期看终端库存、企业库存、日销售额订单
- **芯片价格**:反映周期波动的高频指标
- 价格与库存是短期周期高频指标;产能供给与利用率是中长期指标

### 估值方法
- 高景气阶段:PE(成长属性),可结合 PS(周期底部亏损期)
- 周期下行阶段:关注 PB 与产能价值,警惕盈利下滑
- A股半导体指数与费城半导体指数映射联动,可参考海外周期位置

## 新能源行业(光伏/锂电)

### 光伏产业链
- 全产业链:硅料 → 硅片 → 电池 → 组件(上游价格锚点:多晶硅均价)
- 核心逻辑:成长 + 周期 + 政策 + 产能过剩 + 技术迭代
- 当前特征:产能过剩与价格内卷是主要矛盾,行业处于盈利底部

| 环节 | 核心跟踪指标 |
|------|-------------|
| 硅料(上游锚点) | 多晶硅均价、新建产能投产进度、电力成本、进口料价格 |
| 硅片 | 尺寸迭代、薄片化、石英坩埚瓶颈、出货量 |
| 电池/组件 | 开工率、能效等级政策、价格、库存 |

- 周期判断:产能紧缺→暴利;产能过剩→亏损现金流。跟踪产能投放节奏与开工率
- 政策变量:能耗限额、能效等级新规会强制淘汰高能耗产能

### 锂电池产业链
- 上游:锂矿/碳酸锂(价格高度依赖矿端供给,2023年碳酸锂曾从50万跌至10万元/吨,跌超80%)
- 中游:正极/负极/电解液/隔膜 → 电池(宁德时代等龙头集中)
- 下游:新能源车、储能(储能是新增量)

| 指标 | 说明 |
|------|------|
| 碳酸锂价格 | 上游价格锚点,反映供需 |
| 电池产量/装机量 | 消费型/储能型/动力型分开看 |
| 产能利用率 | 头部公司利用率高,低端产能过剩 |
| 库存周期 | 产能和库存周期触底时是配置窗口 |

### 估值方法
- 周期底部:关注产能出清进度、现金流、PB
- 成长兑现期:PE/PEG,关注新技术(固态电池、钙钛矿等)带来的估值弹性

## 银行行业

### 行业属性
- 高杠杆经营,盈利主要来自存贷利差
- 低估值、高股息、业绩稳定的核心板块

### 核心财务指标
| 指标 | 定义/说明 |
|------|-----------|
| 净息差 NIM | 生息资产与计息负债利差收益,盈利核心 |
| 不良贷款率 | 资产质量核心指标,越低越好 |
| 拨备覆盖率 | 风险抵补能力(150%合规基准),越高分红确定性越强 |
| ROE(加权) | 股东回报,银行股核心指标 |
| 资本充足率 | 抗风险与扩张能力 |

### 估值方法(关键)
- **银行股用 PB 而非 PE**:净资产可比性高,PE 受拨备政策影响失真
- 低 PB + 低不良 + 高拨备 = 优质(高PB合理);低 PB + 高不良 + 低拨备 = 陷阱(未来可能补提坏账)
- 结合净息差趋势、资产质量、资产负债结构综合判断
- 高股息策略下关注分红率与股息率

## 医药行业

### 行业属性
- 政策驱动强(医保、集采、创新药谈判、医疗服务价格调整)
- 细分众多:创新药、仿制药、中药、医疗器械、医疗服务、CXO、医药流通,各自逻辑不同
- "创新不集采,集采非创新":创新药不受集采影响,这是当前最重要的政策边界

### 创新药(当前逻辑最顺畅的子行业)
- 政策支持:《全链条支持创新药发展实施方案》
- 全球研发突破 + 中国产业优势 + 出海潜力(Biotech License-out)
- 核心跟踪:研发管线(临床阶段、适应症、BD授权)、海外进展、现金流

### 医疗器械/仿制药
- 集采影响:仿制药集采压价明显,看量的逻辑
- 器械:关注集采范围扩大与国产替代

### 观察维度
| 维度 | 说明 |
|------|------|
| 政策 | 集采目录、医保谈判、DRG/DIP 按病种付费、行业整顿 |
| 研发管线 | 创新药管线健康度、临床数据、审批进度 |
| 业绩 | 营收/利润增速、研发费用率、现金流 |
| 估值 | 创新药看管线价值(Pipeline)、传统药看 PE |

### 估值方法
- 传统医药:PE,集采影响下关注业绩确定性
- 创新药:管线折现估值(Pipeline Valuation)/可比公司,PE 常失真
- 中药:品牌消费品属性,可看 PE + 分红

## 通用行业分析流程

1. 明确行业属性(周期/成长/消费/金融,或复合)
2. 找产业链位置与价格锚点(上游价格 → 中游加工 → 下游需求)
3. 识别核心指标(3-5个高频指标 + 2-3个中长期指标)
4. 判断当前周期位置(库存/价格/产能利用率/政策)
5. 选择匹配的估值方法(PB/PE/PS/PEG/管线估值)
6. 结合个股基本面、新闻舆情交叉验证
7. 输出时标注"行业景气为阶段性判断,需结合最新数据"

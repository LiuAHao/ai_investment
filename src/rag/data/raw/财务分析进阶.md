# 财务分析进阶

## 适用范围

本手册记录盈利能力、营运能力、偿债能力、现金流质量、资产质量的进阶分析方法,供 Agent 深入分析个股基本面时使用。所有指标口径遵循《指标口径说明》库,分析方法为确定性方法论。

## 一、杜邦分析:ROE 的三因子拆解

### 核心公式
```
ROE = 销售净利率 × 总资产周转率 × 权益乘数
    = (净利润/营业收入) × (营业收入/总资产) × (总资产/净资产)
```

### 三因子含义
| 因子 | 公式 | 代表能力 | 高质量来源 |
|------|------|---------|-----------|
| 净利率 | 净利润÷营业收入 | 定价权/盈利水平 | 品牌壁垒、产品竞争力 |
| 总资产周转率 | 营业收入÷总资产 | 运营效率 | 商业模式、库存管理 |
| 权益乘数 | 总资产÷净资产 | 财务杠杆 | 负债经营(高杠杆是双刃剑) |

### 五因子扩展(进阶)
```
ROE = 税负率 × 息税前利润率 × 总资产周转率 × 权益乘数
其中:税负率 = 净利润/税前利润,息税前利润率 = 息税前利润/营业收入
```

### 分析要点
- **辨别护城河来源**:高 ROE 由净利率驱动(定价权)质量最高;由周转率驱动(效率)次之;由高杠杆驱动(权益乘数大)最脆弱,一旦去杠杆 ROE 会骤降
- 横向比较必须同行业(净利率/周转率行业差异巨大)
- 与历史比较看 ROE 改善/恶化来自哪个因子,定位驱动因素
- 局限性:ROE 受会计政策(折旧、存货计价)影响,需结合现金流验证
- 系统内数据:东财杜邦比较 `stock_zh_dupont_comparison_em`(含 ROE-24A、净利率、总资产周转率、权益乘数)

## 二、盈利质量分析

### 核心指标
| 指标 | 公式 | 判断标准 | 风险信号 |
|------|------|---------|---------|
| 净现比 | 经营现金流净额÷净利润 | 长期>0.8 正常,>1 优秀 | 长期<0.5 警惕盈利不实 |
| 收现比 | 销售商品收到现金÷营业收入 | 长期>1 优秀,0.8-1 可接受 | 长期<0.8 警惕回款差/虚增收入 |
| 现金营运指数 | 经营现金净流量÷经营所得现金 | ≥1 说明收益全部转化为现金 | <1 说明部分利润未收现 |
| 自由现金流 FCF | 经营现金流-资本开支 | 持续为正说明可持续分红/再投资 | 长期为负需融资续命 |

### 分析要点
- **利润是观点,现金是事实**:净利润受会计估计(坏账、折旧、减值)影响,经营现金流更接近真实经营
- 长期看经营现金流与净利润应大致匹配;净利润高但现金流长期偏低需特别警惕(应收账款堆积、存货积压、收入虚增)
- 关键对比:经营现金流与净利润趋势一致性 + 净现比/收现比的连续多期观察
- 警惕"纸面富贵":高净利润+低经营现金流+高应收账款组合,财务造假常见特征
- 分红融资比:长期分红多于融资(造血型)优于持续融资(输血型)

## 三、资产质量与风险指标

### 应收账款
- 应收账款周转天数(DSO)= 平均应收账款÷营业收入×365,与行业对比
- **DSO 显著延长** → 下游需求减弱或回款能力下降
- 账龄恶化(1年以上占比上升)+ 周转率下降 → 重大风险信号
- 客户集中度:前五大客户占比超 50% → 重大依赖风险
- 关注应收账款与合同资产的合计变化,防会计分类美化

### 存货
- 存货周转率 = 营业成本÷存货平均余额,反映存货管理效率
- 存货周转放缓 + 存货金额攀升 → 滞销信号(注意:对某些行业如白酒,渠道库存是主动蓄水,需区分)
- 存货跌价风险:技术迭代快的行业(消费电子、半导体)存货贬值快

### 商誉与减值
- 商誉 = 并购溢价,账面资产中最"虚"的部分
- 高商誉占比(如商誉/净资产>30%)+ 业绩不达预期 → 减值暴雷风险
- 关注管理层历史并购与减值计提习惯

### 负债与偿债
- 资产负债率 = 总负债÷总资产(行业差异大,金融/地产天然高)
- 有息负债规模与结构(短期 vs 长期)、利息保障倍数
- 流动比率/速动比率(短期偿债,制造业参考)
- 警惕"存贷双高":账上大量货币资金同时大量有息负债(疑似资金被占用/造假)

## 四、毛利率与成长质量

### 毛利率趋势
- 毛利率 = (营业收入-营业成本)÷营业收入
- 观察 3-5 年趋势:毛利率提升→产品升级/成本下降/定价权增强;下滑→竞争加剧/成本上升
- 与同行对比判断是否具备持续竞争优势
- 高毛利率(>50%)且稳定 → 强品牌/技术壁垒信号(如高端白酒、半导体材料)

### 成长质量
- 营收增速 vs 利润增速对比:利润增速持续快于营收 → 经营杠杆/费用优化;慢于营收 → 费用失控
- 扣非净利润(剔除非经常性损益)更真实反映主业
- 警惕"增收不增利"(收入增长但利润率下滑)

## 五、财务分析检查清单

1. ROE 水平与趋势 → 杜邦三因子定位驱动
2. 净现比/收现比 → 盈利是否有现金支撑
3. 应收账款周转与账龄 → 收入质量
4. 存货周转趋势 → 滞销/跌价风险
5. 商誉占比与历史减值 → 并购雷区
6. 资产负债率与有息负债 → 偿债与财务风险
7. 毛利率 3-5 年趋势与同行对比 → 竞争壁垒
8. 扣非利润 vs 报表利润 → 主业真实盈利能力

## 使用注意

- 所有对比需同行业、同口径(遵循《指标口径说明》)
- 指标异常需回溯财报附注与经营业务解释,避免单指标误判
- 财务数据以定期报告披露为准,实时接口(Tushare/AKShare)可能滞后或字段口径差异
- 分析方法为确定性方法论,不构成投资建议;结论需结合行情、新闻、行业框架交叉验证

## 第一部分：宏观环境分析

### 1.1 PESTEL分析框架

| 维度 | 分析要点 | 数据来源 |
|------|----------|----------|
| **P-政治** | 监管政策、产业政策、税收政策、贸易政策 | 国务院、发改委、行业协会 |
| **E-经济** | GDP增速、利率水平、通胀率、居民可支配收入、消费信心指数 | 国家统计局、央行 |
| **S-社会** | 人口结构、消费习惯变迁、文化趋势、城镇化率 | 人口普查、社会学研究 |
| **T-技术** | 技术迭代速度、颠覆性创新、专利布局、数字化程度 | 专利数据库、科技媒体 |
| **E-环境** | ESG要求、碳中和政策、环保法规、可持续消费 | 环保部、ESG评级机构 |
| **L-法律** | 行业准入门槛、数据安全法、反垄断法、消费者权益保护 | 法律法规数据库 |

### 1.2 行业生命周期判断

```
导入期 → 成长期 → 成熟期 → 衰退期
  ↓       ↓       ↓       ↓
高风险   高成长   稳定现金  价值陷阱
```

**判断标准：**
- **市场规模增速**：>30%（成长期）、10-30%（成熟期）、<10%（衰退期）
- **渗透率水平**：<10%（导入期）、10-50%（成长期）、>50%（成熟期）
- **竞争格局**：分散（成长期）、集中（成熟期）、萎缩（衰退期）
- **盈利水平**：ROE趋势、毛利率稳定性

## 第二部分：行业竞争格局分析（波特五力模型）

### 2.1 五力分析框架

| 竞争力量 | 关键问题 | 评估维度 | 影响程度 |
|----------|----------|----------|----------|
| **供应商议价能力** | 上游集中度高吗？转换成本高吗？ | 供应商数量、替代原材料可得性、前向一体化威胁 | ⭐⭐⭐⭐⭐ |
| **购买者议价能力** | 客户集中吗？价格敏感吗？ | 客户数量、转换成本、后向一体化能力、信息透明度 | ⭐⭐⭐⭐⭐ |
| **潜在进入者威胁** | 进入壁垒高吗？新玩家多吗？ | 规模经济、资本需求、技术壁垒、政策准入、品牌忠诚度 | ⭐⭐⭐⭐⭐ |
| **替代品威胁** | 有其他满足需求的方式吗？ | 性价比比较、转换成本、技术替代趋势 | ⭐⭐⭐⭐⭐ |
| **行业内竞争** | 竞争激烈吗？价格战频繁吗？ | 竞争者数量、行业增速、固定成本占比、差异化程度、退出壁垒 | ⭐⭐⭐⭐⭐ |

### 2.2 竞争格局矩阵

| 格局类型 | 特征描述 | 投资策略 | 典型案例 |
|----------|----------|----------|----------|
| **完全垄断** | 单一企业控制市场，高壁垒 | 长期持有，关注政策风险 | 烟草、铁路 |
| **寡头垄断** | 2-5家头部企业主导，格局稳定 | 优选龙头，关注第二名机会 | 白酒、航空 |
| **垄断竞争** | 差异化竞争，品牌分散 | 寻找品牌力突出的细分龙头 | 乳制品、服装 |
| **完全竞争** | 同质化严重，价格战激烈 | 回避或寻找成本极致领先者 | 大宗商品、纺织 |

## 第三部分：护城河分析框架

### 3.1 护城河四维评估模型

根据沃伦·巴菲特和帕特·多尔西的理论，护城河分为四大类型：

#### 3.1.1 无形资产护城河
| 类型 | 定义 | 评估指标 | 适用行业 |
|------|------|----------|----------|
| **品牌** | 心智占领带来的定价权 | 品牌溢价率、市占率、复购率 | 消费、奢侈品 |
| **专利** | 技术独占性 | 专利数量、专利剩余保护期、核心专利占比 | 医药、科技 |
| **牌照/特许经营权** | 政策准入壁垒 | 牌照稀缺性、政策壁垒强度 | 金融、公用事业、博彩 |

#### 3.1.2 转换成本护城河
| 类型 | 定义 | 评估指标 | 适用行业 |
|------|------|----------|----------|
| **客户转换成本** | 客户更换供应商的成本 | 客户流失率、客户生命周期价值（LTV） | SaaS、银行、软件 |
| **网络效应** | 用户越多，产品价值越高 | 用户规模、网络密度、跨边网络效应 | 互联网平台、社交网络 |
| **生态系统锁定** | 多产品协同增加粘性 | 交叉销售率、生态内产品使用数量 | 苹果、腾讯、微软 |

#### 3.1.3 成本优势护城河
| 类型 | 定义 | 评估指标 | 适用行业 |
|------|------|----------|----------|
| **规模经济** | 单位成本随规模下降 | 产能利用率、单位制造成本vs行业平均 | 制造业、零售 |
| **范围经济** | 多元化降低成本 | 共享成本占比、品类协同效应 | 平台型公司 |
| **地理位置** | 运输成本优势 | 物流半径、区域市场密度 | 水泥、啤酒 |
| **独特资源** | 稀缺原材料控制权 | 资源储量、开采成本vs全球成本曲线 | 矿业、石油 |

#### 3.1.4 有效规模护城河
| 类型 | 定义 | 评估指标 | 适用行业 |
|------|------|----------|----------|
| **区域垄断** | 有限市场仅能容纳少数玩家 | 区域市场集中度、产能利用率 | 有线电视、地方银行 |
| **利基市场** | 细分市场龙头 | 细分市占率、进入者数量 | 专业设备、工业软件 |

### 3.2 护城河评分表

| 评估维度 | 权重 | 评分标准（1-5分） | 得分 |
|----------|------|------------------|------|
| 品牌强度 | 20% | 1=无认知，5=品类代名词 | |
| 客户粘性 | 20% | 1=高流失，5=极高转换成本 | |
| 成本领先 | 20% | 1=无优势，5=绝对成本领先 | |
| 网络效应 | 15% | 1=无网络，5=强网络效应 | |
| 监管壁垒 | 15% | 1=无壁垒，5=特许经营权 | |
| 技术壁垒 | 10% | 1=易模仿，5=核心技术垄断 | |
| **综合评分** | **100%** | **总分≥4.0为宽护城河，3.0-4.0为中等护城河，<3.0为窄护城河** | |

## 第四部分：分行业深度研究框架

### 4.1 消费行业研究框架

#### 4.1.1 行业特性
- **弱周期性**：需求相对稳定，与经济周期相关性中等
- **高品牌溢价**：差异化空间大，护城河主要来自品牌
- **渠道为王**：终端触达能力决定增长天花板

#### 4.1.2 核心分析维度

| 维度 | 关键指标 | 分析方法 |
|------|----------|----------|
| **需求端** | 人口结构、人均消费量、品类渗透率、消费分级 | 自上而下测算市场空间 |
| **供给端** | 产能布局、供应链效率、原材料成本波动 | 产业链上下游调研 |
| **竞争格局** | CR3/CR5、品牌矩阵、渠道掌控力 | 波特五力+市场份额分析 |
| **增长驱动** | 量价拆分、品类扩张、区域扩张、渠道变革 | 杜邦分析+增长因子分解 |

#### 4.1.3 消费品估值模型
| 估值方法 | 适用场景 | 公式 |
|----------|----------|------|
| **PE估值** | 盈利稳定的成熟品牌 | P = EPS × 行业PE中位数 × 品牌溢价系数 |
| **PEG估值** | 高成长消费品 | PEG = PE / G（增速），通常<1.5为合理 |
| **PS估值** | 新兴品牌或扩张期 | P = 收入 × PS倍数（参考同品类） |
| **DCF估值** | 具有稳定现金流的龙头 | 三阶段DCF模型 |

#### 4.1.4 关键护城河识别
```
1. 品牌护城河：茅台（白酒=茅台）、海天（酱油=海天）
2. 渠道护城河：农夫山泉（毛细血管网络）、伊利（终端冰柜占领）
3. 供应链护城河：Costco（极致效率）、Shein（小单快反）
4. 心智护城河：可口可乐（百年品牌积淀）
```

### 4.2 科技行业研究框架

#### 4.2.1 行业特性
- **强周期性**：技术迭代快，产品生命周期短
- **高不确定性**：技术路线风险、颠覆式创新风险
- **网络效应显著**：平台型公司赢家通吃

#### 4.2.2 核心分析维度

| 维度 | 关键指标 | 分析方法 |
|------|----------|----------|
| **技术迭代** | 摩尔定律适用性、技术代际差、研发投入占比 | 技术路线图（Roadmap）分析 |
| **产品周期** | 产品生命周期阶段、迭代速度、SKU管理 | 波士顿矩阵+生命周期分析 |
| **生态构建** | 开发者数量、应用丰富度、平台控制力 | 生态系统健康度评估 |
| **竞争壁垒** | 技术专利、数据积累、算法优势、迁移成本 | 护城河四维评估 |

#### 4.2.3 科技企业估值模型
| 估值方法 | 适用场景 | 特点 |
|----------|----------|------|
| **P/S估值** | 高成长未盈利科技股 | 关注收入增长质量（SaaS用ARR） |
| **EV/EBITDA** | 资本结构差异大的公司 | 剔除折旧摊销影响 |
| **P/FCF** | 现金流为王的成熟期科技 | 反映真实现金创造能力 |
| **用户价值法** | 互联网平台 | 单用户价值（ARPU）× 用户数 × 变现系数 |
| **SOTP估值** | 多元化科技集团 | 分部估值加总（如阿里、腾讯） |

#### 4.2.4 关键护城河识别
```
1. 技术护城河：台积电（制程领先）、ASML（光刻机垄断）
2. 网络护城河：微信（社交图谱）、Meta（连接数）
3. 生态护城河：苹果（软硬件一体化）、安卓（开源生态）
4. 数据护城河：Google（搜索数据）、Palantir（政府数据）
5. 迁移成本：Oracle（企业软件）、Salesforce（CRM数据）
```

#### 4.2.5 技术成熟度曲线（Gartner Hype Cycle）
```
技术萌芽期 → 期望膨胀期 → 泡沫破裂期 → 稳步爬升期 → 生产成熟期
     ↓            ↓            ↓            ↓            ↓
  早期投资     概念炒作     风险暴露     价值投资     现金牛
```

### 4.3 金融行业研究框架

#### 4.3.1 银行子行业

**核心特征**：高杠杆、强监管、周期性、重资产

| 分析维度 | 关键指标 | 说明 |
|----------|----------|------|
| **盈利能力** | 净息差（NIM）、非息收入占比、ROE | NIM反映核心盈利能力 |
| **资产质量** | 不良贷款率（NPL）、拨备覆盖率、关注类贷款占比 | 决定长期生存 |
| **资本充足** | 核心一级资本充足率、资本充足率 | 监管红线7.5%/10.5% |
| **负债结构** | 存款占比、核心负债依存度、同业负债占比 | 决定资金成本 |
| **成长能力** | 总资产增速、贷款增速、中收增速 | 规模与质量平衡 |

**估值模型：**
| 方法 | 公式/逻辑 | 适用场景 |
|------|-----------|----------|
| **P/B-ROE模型** | P/B = (ROE - g) / (r - g)，合理P/B = ROE/COE | 银行股主流估值 |
| **DDM模型** | 股利贴现，三阶段模型 | 分红稳定的国有大行 |
| **EVA模型** | 经济增加值 = (ROE - r) × B | 价值创造能力评估 |
| **清算价值** | 净资产 - 不良资产拨备 | 破产风险评估 |

#### 4.3.2 券商子行业

**核心特征**：轻资产、高波动、强Beta、监管敏感

| 业务板块 | 收入驱动因素 | 核心指标 |
|----------|--------------|----------|
| **经纪业务** | 市场成交额、佣金率、市占率 | 股基成交额、净佣金率 |
| **投行业务** | IPO/再融资规模、债券承销、项目储备 | 承销金额、储备项目数 |
| **资管业务** | 管理规模（AUM）、费率结构、主动管理能力 | AUM、综合费率、业绩报酬 |
| **自营业务** | 市场波动、资产配置、衍生品策略 | 投资收益率、风险敞口 |
| **信用业务** | 两融规模、股票质押、利息收入 | 融出资金规模、坏账率 |

**估值模型：**
| 方法 | 适用场景 | 关键点 |
|------|----------|--------|
| **P/E** | 牛市高盈利期 | 关注盈利波动 |
| **P/B** | 熊市低盈利期 | 净资产安全边际 |
| **分部估值** | 多元化券商 | 各项业务分别估值加总 |
| **AUM倍数** | 财富管理业务 | 类似资管公司估值 |

#### 4.3.3 保险子行业

**核心特征**：长负债久期、精算定价、投资驱动、EV估值

**寿险分析框架：**
| 维度 | 核心指标 | 说明 |
|------|----------|------|
| **销售能力** | 新业务价值（NBV）、NBV增速、价值率（Margin） | 增长引擎 |
| **渠道质量** | 代理人产能、银保渠道价值率、互联网渠道占比 | 渠道效率 |
| **运营能力** | 费用率、赔付率、继续率 | 费差与死差 |
| **投资能力** | 投资收益率、资产配置结构、非标占比 | 利差来源 |
| **偿付能力** | 偿付能力充足率、核心偿付能力 | 监管安全垫 |

**估值模型：**
| 方法 | 公式 | 适用场景 |
|------|------|----------|
| **内含价值法（EV）** | EV = 调整后净资产 + 有效业务价值（VIF） | 寿险标准估值 |
| **P/EV倍数** | 市值 / 内含价值，类比P/B | 相对估值 |
| **新业务价值倍数** | 市值 / NBV | 成长型寿险 |
| **分部估值** | 寿险EV + 其他业务市值 | 综合保险集团 |

## 第五部分：财务分析框架

### 5.1 通用财务指标体系

| 类别 | 指标 | 计算公式 | 分析意义 |
|------|------|----------|----------|
| **盈利能力** | 毛利率 | (收入-成本)/收入 | 产品竞争力 |
| | 净利率 | 净利润/收入 | 综合盈利能力 |
| | ROE | 净利润/净资产 | 股东回报 |
| | ROIC | 税后经营利润/投入资本 | 真实经营效率 |
| **运营效率** | 资产周转率 | 收入/总资产 | 资产利用效率 |
| | 存货周转天数 | 365/(成本/平均存货) | 供应链效率 |
| | 应收账款周转天数 | 365/(收入/平均应收) | 回款能力 |
| **偿债能力** | 资产负债率 | 负债/资产 | 财务风险 |
| | 利息保障倍数 | EBIT/利息费用 | 偿债安全垫 |
| | 现金流利息保障 | 经营现金流/利息 | 真实现金偿债能力 |
| **成长能力** | 收入增长率 | (本期-上期)/上期 | 市场扩张 |
| | 净利润增长率 | (本期-上期)/上期 | 盈利扩张 |
| | 自由现金流增长率 | FCF变动率 | 价值创造 |

### 5.2 杜邦分析（ROE分解）

```
ROE = 净利润率 × 资产周转率 × 权益乘数
       (盈利能力)  (运营效率)   (杠杆水平)
       
消费行业：高利润率 × 低周转 × 低杠杆
科技行业：中高利润率 × 高周转 × 中杠杆
金融行业：低利润率（息差） × 极低周转 × 高杠杆
```

## 第六部分：估值与投资建议

### 6.1 估值方法选择矩阵

| 行业类型 | 首选方法 | 次选方法 | 慎用方法 |
|----------|----------|----------|----------|
| 消费-成熟期 | DCF/DDM | P/E、EV/EBITDA | P/S |

| 券商 | P/B、P/E | 分部估值 | DCF |
| 保险 | P/EV | NBV倍数 | P/E |

### 6.2 投资建议框架

| 评估维度 | 权重 | 评分 | 说明 |
|----------|------|------|------|
| 行业景气度 | 20% | | 行业增速、政策支持 |
| 公司护城河 | 25% | | 竞争壁垒可持续性 |

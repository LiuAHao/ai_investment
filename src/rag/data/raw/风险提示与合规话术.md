# 风险提示与合规话术规范文档

**文档编号：** [COMP-2024-RISK-001]  
**适用对象：** 金融产品销售人员、投资顾问、客户经理、合规管理人员  
**生效日期：** 2024年  
**编制依据：** 《证券期货投资者适当性管理办法》《证券投资顾问业务暂行规定》《关于规范金融机构资产管理业务的指导意见》等

## 一、常见风险类型与合规表述

### 1.1 市场风险

| 风险类型 | 不合规表述（禁止） | 合规表述（推荐） | 法规依据 |
|---------|------------------|----------------|---------|
| **市场波动风险** | "稳赚不赔"、"只涨不跌"、"肯定赚钱" | "本产品可能因市场波动导致本金亏损，过往业绩不代表未来表现" | 《证券期货投资者适当性管理办法》第22条 |
| **系统性风险** | "绝对安全"、"零风险"、"保本保息" | "本产品面临系统性风险，在市场极端情况下可能产生较大损失" | 《资管新规》 |
| **流动性风险** | "随时赎回"、"资金灵活"、"T+0到账" | "本产品设有封闭期/赎回限制，投资者需关注流动性安排，提前赎回可能产生损失" | 《证券期货投资者适当性管理办法》第23条 |

**合规话术模板：**
> "尊敬的投资者，本产品为R3（中风险）等级，投资于股票市场，可能因市场价格波动导致本金出现10%-30%的亏损。请您根据自身风险承受能力谨慎决策。"

### 1.2 信用风险

| 风险类型 | 不合规表述（禁止） | 合规表述（推荐） |
|---------|------------------|----------------|
| **违约风险** | "国企背景绝对安全"、"政府兜底"、"100%兑付" | "本产品投资标的涉及信用风险，如发行主体发生违约，可能导致本金及收益损失" |
| **交易对手风险** | "大机构担保没问题"、"银行背书" | "本产品存在交易对手风险，管理人将严格选择交易对手并进行持续跟踪，但无法完全消除风险" |

### 1.3 操作与管理风险

| 风险类型 | 不合规表述（禁止） | 合规表述（推荐） |
|---------|------------------|----------------|
| **管理风险** | "明星经理操盘肯定行"、"过往业绩优异未来必然好" | "投资管理团队过往业绩仅供参考，不预示未来表现，存在因管理不善导致损失的可能" |
| **操作风险** | "系统绝对安全"、"技术保障无虞" | "本产品可能面临系统故障、操作失误等风险，管理人已建立风控体系但不能完全避免" |

### 1.4 合规风险红线（绝对禁止）

根据《证券期货经营机构私募资产管理业务运作管理暂行规定》及近期监管处罚案例，以下表述**严禁使用**：

**绝对禁止词汇：**
- 保本类：保本、保息、保收益、本金无忧、零风险、无风险
- 确定性承诺：肯定、确保、一定、必然、绝对、100%
- 误导性暗示：安全、保险、避险、有保障、高收益、稳赚
- 刚兑暗示：预期收益率（变相刚兑表述）、约定收益率、未来收益率、历史业绩暗示未来

**典型违规案例分析：**
- 迈科期货案：因资管计划宣传材料存在"与实际情况不符的误导性表述"被出具警示函
- 中金财富厦门分公司案：使用"安全"、"年化收益率"等误导性措辞，向投资者推介超出风险承受能力的产品

## 二、合规表达方式与话术规范

### 2.1 投资者适当性管理话术

#### 2.1.1 风险测评环节

**标准话术：**
> "根据《证券期货投资者适当性管理办法》规定，我需要向您了解以下信息，请您如实告知：您的投资经验、财务状况、投资目标及风险偏好。这些信息将帮助我们评估您的风险承受能力，确保推荐适合您的产品。"

**禁止行为：**
- ❌ 代客户填写风险测评问卷
- ❌ 引导客户选择特定答案以通过测评
- ❌ "您就选C1（保守型），这样可以买更多产品"

#### 2.1.2 产品风险告知（双录话术）

**必须包含的要素：**
1. **产品基本信息**：产品名称、类型、期限、投资范围
2. **风险等级**：明确告知R1-R5风险等级含义
3. **本金损失可能性**：具体说明最大可能亏损幅度
4. **流动性安排**：封闭期、赎回限制、提前终止条件
5. **费用结构**：申购费、管理费、托管费、赎回费
6. **业绩基准说明**：不等于承诺收益

**双录标准话术模板：**
> "我现在向您介绍XX产品的风险特征：该产品风险等级为R4（中高风险），主要投资于股票市场，可能因市场波动导致本金亏损**20%-50%**。产品设有6个月封闭期，封闭期内不得赎回。本产品业绩比较基准为6%，**但这不预示实际收益，也不构成收益承诺**。请问您是否清楚以上风险？"

**留痕要求：** 录音录像资料保存期限不得少于20年

### 2.2 营销推介话术规范

#### 2.2.1 收益表述规范

| 场景 | 不合规表述 | 合规表述 |
|-----|-----------|---------|
| 介绍业绩比较基准 | "预期收益8%" | "业绩比较基准为8%，实际收益可能高于或低于该基准，甚至可能出现亏损" |
| 介绍历史业绩 | "去年赚了20%，今年肯定也不错" | "过去三年年化收益率区间为-5%至15%，历史业绩不代表未来表现" |
| 业绩排名 | "排名第一，行业最佳" | "过去三年同类型产品中排名位于前30%，排名仅供参考不构成投资建议" |

#### 2.2.2 产品对比规范

**禁止行为：**
- ❌ "我们的产品比银行理财产品安全多了"
- ❌ "肯定比你自己炒股强"
- ❌ "其他公司的产品都不行，只有我们的好"

**合规表述：**
> "不同产品的风险收益特征不同，银行理财产品通常风险等级较低，而本产品为权益类产品，风险等级较高，请您根据自身情况选择适合的产品。"

### 2.3 投资顾问服务话术

#### 2.3.1 投资建议规范

**必须做到的：**
- ✅ 注明投资顾问姓名及登记编码
- ✅ 说明投资建议的合理依据
- ✅ 提示潜在投资风险
- ✅ 告知信息来源及局限性

**标准话术：**
> "我是XX公司的投资顾问XXX（登记编码：AXXXXXXXXX），基于当前市场环境分析，XX板块近期呈现XX特征，**但这仅是基于公开信息的分析判断，不构成买卖建议**。股票价格受多种因素影响，投资需谨慎，建议您根据自身风险承受能力独立决策。"

#### 2.3.2 禁止的指令性表述

根据深圳证监局2022年处罚案例，以下词汇**禁止使用**：

**禁止使用的指令性词汇：**
- "买入"、"卖出"、"建仓"、"清仓"
- "关注"、"重点看好"、"强烈推荐"
- "必涨"、"马上拉升"、"目标价位"

**案例分析：**
- 深圳德讯证券顾问案：因营销人员使用"建仓"等误导性表述被责令改正
- 博众投资案：因暗示收益、误导性宣传多次被罚

## 三、避免指令性买卖建议的具体规范

### 3.1 投资咨询与指令建议的界限

| 合规行为（投资咨询） | 违规行为（指令建议） |
|-------------------|-------------------|
| "从基本面看，该公司业绩稳健，但估值偏高，投资者需谨慎评估" | "现在马上买入，目标价XX元" |
| "该板块近期受政策影响较大，建议投资者关注相关风险" | "赶紧关注这只股票，明天肯定涨" |
| "基于技术面分析，该股票呈现多头排列，但需注意市场系统性风险" | "强烈建议建仓，这波至少赚20%" |

### 3.2 投资建议的合规结构

**合规投资建议四要素：**

1. **依据说明**：基于公开信息/研究报告/技术分析
   > "根据公司2024年三季报及行业研究报告..."

2. **风险提示**：明确告知不确定性和风险
   > "但需注意，该预测基于当前市场环境，存在重大不确定性..."

3. **免责声明**：不构成买卖建议，投资者自主决策
   > "以上分析仅供参考，不构成具体买卖建议..."

4. **资质展示**：注明投顾姓名及登记编码
   > "投资顾问：XXX，执业编号：AXXXXXXXXX"

**完整合规话术示例：**
> "根据XX公司2024年三季报显示，其营收同比增长15%，净利润率有所提升。从行业角度看，政策环境较为友好。**但需注意**，公司面临原材料价格波动风险，且当前估值处于历史高位，**以上分析基于公开信息，仅供参考，不构成具体买卖建议**。投资者应根据自身风险承受能力独立判断。投资顾问：XXX（登记编码：AXXXXXXXXX）。"

### 3.3 营销材料的合规审核要点

根据监管要求，对外发布的营销材料必须经过合规审查并留痕：

**审核清单：**
- [ ] 是否包含保本保收益暗示
- [ ] 是否使用"安全"、"保证"等误导性词汇
- [ ] 是否标注"历史业绩不代表未来表现"
- [ ] 是否注明产品风险等级
- [ ] 是否包含投资顾问姓名及登记编码（如适用）
- [ ] 免责声明是否完整
- [ ] 是否涉及具体买卖指令
- [ ] 是否经过合规部门审核并留痕

## 四、特殊场景合规话术

### 4.1 客户询问具体买卖时机

**客户：** "老师，我现在该不该买？"

**不合规回应：** "现在就是买入时机，赶紧建仓！"

**合规回应：** "我无法为您判断具体买卖时机。投资决策需您基于自身财务状况、投资目标和风险承受能力独立做出。我可以为您分析该产品的风险特征和投资范围，供您参考。建议您阅读产品说明书和风险揭示书，充分了解风险后再做决策。"

### 4.2 客户要求收益承诺

**客户：** "这个产品能保证多少收益？"

**不合规回应：** "虽然合同不能写，但实际上我们肯定能给您做到6%。"

**合规回应：** "根据监管规定，我们**严禁承诺**任何收益水平。本产品业绩比较基准为6%，但这只是基于历史数据和管理人投资策略的参考值，**实际收益可能高于或低于该基准，甚至可能出现本金亏损**。过往业绩数据显示，该产品2022年收益率为-8%，2023年为+12%，存在较大波动。请您充分理解投资风险。"

### 4.3 客户风险承受能力不匹配

**场景：** 客户风险测评结果为C2（稳健型），但希望购买R4（中高风险）产品

**合规处理流程：**

1. **明确告知不匹配：** "根据您的风险测评结果，您为C2型投资者，适合R2及以下风险等级产品。您意向购买的XX产品为R4等级，**风险等级不匹配**，我可能无法向您推介。"

2. **如客户坚持：** "如果您坚持购买，我需要为您进行**特别风险警示**：该产品风险等级高于您的承受能力，可能导致本金大幅亏损，且封闭期内无法赎回。请您签署《风险不匹配警示函及投资者确认书》。"

3. **给予冷静期：** "请您回去考虑至少24小时，充分评估自身风险承受能力后再做决定。"

**禁止行为：** 不得主动推介风险等级高于客户承受能力的产品

## 五、合规管理体系建设

### 5.1 内部管理制度要求

根据《证券期货投资者适当性管理办法》，经营机构应建立：

1. **适当性内部管理制度**：明确投资者分类、产品分级、适当性匹配的具体依据和方法
2. **风控制度**：限制不匹配销售行为、客户回访检查、评估与销售隔离
3. **培训考核制度**：定期开展合规培训，确保从业人员掌握规范话术
4. **监督问责制度**：对违规行为进行追责
5. **自查制度**：每半年开展一次适当性自查，形成自查报告

### 5.2 禁止的考核激励机制

**禁止：**
- 将销售业绩与薪酬完全挂钩
- 对不匹配销售给予额外奖励
- 以开户数、销量为唯一考核指标

**建议：**
- 建立多维度考核体系，纳入合规指标
- 设置合规红线，一票否决制
- 定期进行合规话术演练和测试

## 六、违规处罚与案例警示

### 6.1 常见违规类型及处罚

根据2024-2025年各地证监局处罚案例：

| 违规类型 | 典型案例 | 处罚措施 |
|---------|---------|---------|
| 误导性宣传 | 迈科期货资管计划宣传材料误导性表述 | 出具警示函 |
| 不当推介 | 中金财富厦门分公司向客户推介超风险等级产品 | 出具警示函，记入诚信档案 |
| 使用禁止词汇 | 使用"安全"、"年化收益率"等误导性措辞 | 出具警示函 |
| 适当性管理缺失 | 深圳德讯证券适当性测评环节后置、营销话术违规 | 责令改正 |
| 自媒体管理失控 | 营销账号未标注投顾信息、免责条款缺失 | 责令改正 |
| 未留痕管理 | 企业微信语音电话未监控、直播内容未审核 | 责令改正 |

### 6.2 违规话术识别与纠正

**自查问题清单：**

1. **是否承诺收益？**
   - 检查：宣传材料中是否出现"预期收益"、"约定收益率"等词汇
   - 纠正：改为"业绩比较基准"，并加粗提示"不代表未来表现"

2. **是否暗示保本？**
   - 检查：是否使用"本金无忧"、"零风险"等表述
   - 纠正：明确标注"本金可能受损"，并量化最大亏损幅度

3. **是否构成指令建议？**
   - 检查：是否出现"买入"、"建仓"、"关注"等指令性词汇
   - 纠正：改为"分析"、"探讨"、"供您参考"等中性表述

4. **是否匹配适当性？**
   - 检查：是否向C1客户推介R3以上产品
   - 纠正：严格执行风险匹配，对不匹配销售进行限制和警示

## 七、合规话术速查手册

### 7.1 常用合规替代词

| 禁用词 | 合规替代词 |
|-------|-----------|
| 保本 | 本金存在损失可能 |
| 保收益 | 收益不确定，可能亏损 |
| 稳赚 | 收益波动，可能盈利也可能亏损 |
| 零风险 | 存在多种风险，包括市场风险、信用风险等 |
| 肯定涨 | 价格受市场影响，涨跌不确定 |
| 安全 | 风险等级为X，适合X类投资者 |
| 最佳时机 | 当前市场环境复杂，需独立判断 |
| 建仓/买入 | 关注/研究/分析（非指令性表述） |
| 绝对 | 存在不确定性 |
| 保证 | 无法确保，存在风险 |

### 7.2 风险等级对应话术

| 风险等级 | 标准话术 |
|---------|---------|
| R1（低风险） | 本产品本金损失概率极低，但不等于完全没有风险，极端情况下仍可能受损 |
| R2（中低风险） | 本产品本金损失概率较小，但存在市场波动导致收益不达预期的风险 |
| R3（中风险） | 本产品可能因市场波动导致本金出现10%-20%的亏损，投资需谨慎 |
| R4（中高风险） | 本产品可能因市场波动导致本金出现20%-50%的亏损，适合风险承受能力较强的投资者 |
| R5（高风险） | 本产品可能因市场波动导致本金全部损失，甚至超过本金（杠杆产品），仅适合风险承受能力最强的投资者 |

## 八、附则

### 8.1 文档更新
本规范应根据最新监管规定及时更新，建议每季度回顾一次。

### 8.2 培训要求
所有销售人员应在入职时及每季度接受本规范培训，并通过考核。

### 8.3 咨询渠道
如遇不确定的合规问题，应咨询合规部门，不得擅自决定。

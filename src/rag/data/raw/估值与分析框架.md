## 一、核心估值方法论

### 1.1 三大估值路径

| 方法类别 | 核心逻辑 | 适用场景 | 主要输出 |
|---------|---------|---------|---------|
| **收益法（Income Approach）** | 企业价值=未来现金流现值 | 成熟企业、稳定现金流、并购估值 | 内在价值（Intrinsic Value） |
| **市场法（Market Approach）** | 企业价值=可比公司交易倍数 | 上市公司、有活跃市场参照、快速估值 | 相对价值（Relative Value） |
| **资产法（Asset Approach）** | 企业价值=资产重置成本-负债 | 重资产行业、清算场景、控股公司 | 净资产价值（NAV） |

### 1.2 方法论选择矩阵

**优先使用DCF的情况**：
- 现金流可预测性强（通常成熟企业ARR>$20M）
- 具有独特商业模式，缺乏直接可比公司
- 并购场景需精确评估协同效应

**优先使用可比公司分析（Comps）的情况**：
- 存在充足同行业上市公司
- 需要快速市场检验DCF结果
- 评估行业估值水平与周期位置

## 二、DCF现金流折现模型详解

### 2.1 模型构建五步法

#### **Step 1: 预测期设定与自由现金流估算**
- **显性预测期**：通常5-10年，需覆盖完整商业周期
- **现金流类型选择**：
  - **FCFF（企业自由现金流）**：折现得到企业价值（EV），适用于资本结构变化大的企业
  - **FCFE（股权自由现金流）**：折现得到股权价值，适用于杠杆稳定的公司

**FCFF计算公式**：
```
FCFF = EBIT × (1 - 税率) + 折旧摊销 - 资本支出 - 营运资本变动
```

#### **Step 2: 折现率确定（WACC）**

**加权平均资本成本（WACC）构成**：
```
WACC = (E/V) × Re + (D/V) × Rd × (1 - Tc)
```

| 参数 | 计算/来源 | 实务区间 |
|------|----------|---------|
| **无风险利率（Rf）** | 10年期国债收益率 | 3.5%-4.5%（2025年美国） |
| **市场风险溢价（ERP）** | 历史超额收益或隐含溢价 | 4.5%-6.0% |
| **Beta（β）** | 可比公司去杠杆后Beta再杠杆化 | 0.7-1.3（视行业） |
| **债务成本（Rd）** | 公司实际借贷利率 | 基准利率+信用利差 |
| **目标资本结构** | 行业均值或公司最优结构 | D/E通常20%-50% |

**2025年参考**：当前政策利率维持在4.0%-4.25%区间，WACC普遍较2021年零利率时期上升200-300bps

#### **Step 3: 终值（Terminal Value）计算**

**方法一：永续增长法（Gordon Growth Model）**
```
TV = FCFₙ × (1 + g) / (WACC - g)
```
- **g（永续增长率）**：通常不超过GDP增速+通胀，实务中1.5%-3.0%
- **适用**：稳定增长期企业，避免终值占比过高（通常<60%总EV）

**方法二：退出倍数法（Exit Multiple）**
```
TV = EBITDAₙ × 行业退出倍数
```
- **倍数选择**：基于正常化周期中位数，避免峰值/谷值
- **适用**：明确退出时间的私募股权场景

#### **Step 4: 折现与价值汇总**

**时间调整要点**：
- **年中折现（Mid-year Convention）**：假设现金流在全年均匀发生，公式为`1/(1+WACC)^(n-0.5)`
- **年末折现**：适用于季节性强的现金流

**企业价值计算**：
```
Enterprise Value = Σ(FCFₜ / (1+WACC)ᵗ) + TV / (1+WACC)ⁿ
```

#### **Step 5: 股权价值推导**

```
Equity Value = Enterprise Value - Net Debt + Non-operating Assets - Minority Interest
```

**净债务（Net Debt）** = 有息负债 - 现金及等价物（需剔除受限现金）

### 2.2 DCF关键假设与敏感性分析

**必须披露的核心假设**：
1. 收入增长率轨迹（分阶段：高速/过渡/稳定）
2. EBIT利润率扩张/收敛路径
3. 资本支出强度（Capex/Revenue）
4. 营运资本周转效率（NWC/Revenue）
5. 税率变化（考虑税收优惠到期）

**敏感性分析矩阵**（必须包含）：

| WACC \ 永续增长率 | 1.5% | 2.0% | 2.5% | 3.0% |
|------------------|------|------|------|------|
| **8.0%** | $X | $X+5% | $X+10% | $X+15% |
| **9.0%** | $X-8% | $X-3% | $X+2% | $X+7% |
| **10.0%** | $X-15% | $X-10% | $X-5% | $X |

**场景分析（Scenario Analysis）**：
- **基础情景（Base Case）**：管理层指引达成
- **上行情景（Upside）**：市场份额超预期、新市场突破
- **下行情景（Downside）**：竞争加剧、宏观经济衰退

## 三、相对估值法（倍数法）

### 3.1 核心估值倍数体系

#### **企业价值倍数（EV Multiples）** - 并购与PE首选

| 倍数 | 计算公式 | 适用行业 | 关键考量 |
|------|---------|---------|---------|
| **EV/Revenue** | 企业价值/营业收入 | SaaS、早期成长企业、亏损企业 | 关注收入质量（经常性vs一次性） |
| **EV/EBITDA** | 企业价值/息税折旧前利润 | 资本密集型、重折旧行业（制造、电信） | 忽略资本支出差异，需结合资本强度 |
| **EV/EBIT** | 企业价值/息税前利润 | 折旧政策差异大的行业 | 更接近经营现金流 |
| **EV/FCF** | 企业价值/自由现金流 | 现金流稳定企业 | 最佳价值指标但波动大 |

#### **股权倍数（Equity Multiples）** - 二级市场常用

| 倍数 | 计算公式 | 适用场景 | 注意事项 |
|------|---------|---------|---------|
| **P/E（市盈率）** | 股价/每股收益 | 盈利稳定、成熟企业 | 受资本结构影响，需区分 trailing/forward |
| **P/B（市净率）** | 股价/每股净资产 | 金融机构、重资产行业 | 资产质量与会计政策差异 |
| **P/S（市销率）** | 市值/营业收入 | 早期成长、暂时亏损企业 | 无法反映盈利能力 |

### 3.2 倍数选择决策树

```
公司特征评估
├─ 盈利性？
│  ├─ 是 → EBITDA/EBIT正向？
│  │     ├─ 是 → 优先EV/EBITDA, 辅以P/E
│  │     └─ 否（重组期）→ EV/Revenue + 前瞻倍数
│  └─ 否（成长期）→ EV/Revenue（关注Rule of 40）
└─ 资本结构稳定性？
   ├─ 是 → 可用P/E
   └─ 否 → 必须用EV倍数（不受杠杆影响）
```

### 3.3 倍数调整因素

**溢价/折价调整逻辑**：
- **+20%溢价**：增长率高于中位数50%+，NRR>120%，毛利率>75%
- **-20%折价**：客户集中度高（>20%收入来自单一客户），烧钱率>2.5x

**2025年市场基准参考**：
- 软件/SaaS中位数：EV/Revenue ~6.1x
- Rule of 40达标企业：~12-15x（溢价100%+）
- AI软件融资轮次：~25-30x（但M&A实际成交多在个位数至低双位数）

## 四、行业对比与可比公司分析

### 4.1 可比公司筛选四维度

**1. 业务相似性（Business Profile）**
- 收入模式（订阅制、交易费、许可费）
- 产品/服务类别与替代性
- 目标客群（Enterprise vs SMB）
- 地理分布与监管环境

**2. 规模可比性（Size）**
- 收入规模：通常±50%范围内
- 市值/企业价值：避免过小流动性差异
- 员工数量与产能

**3. 财务特征（Financial Characteristics）**
- 增长率区间（±10%）
- 利润率水平
- 资本强度（Capital Intensity）

**4. 资本结构（Capital Structure）**
- 杠杆率相似
- 同样处于增长期/成熟期

### 4.3 常见错误与校准

**必须避免的陷阱**：
1. **日历化错误（Calendarization）**：不同财年截止日需调整至同一基准
2. **稀释忽视**：使用完全稀释股数（含期权、可转债）
3. **一次性项目**：调整非经常性损益（重组费用、资产处置）
4. **净债务时点**：市值与财务数据需对应同一日期

**Excel建模最佳实践**：

- 公式链接：黑色字体
- 跨表引用：绿色字体
- 假设注释：底部脚注详细说明

## 五、成长性判断与质量评估

### 5.1 SaaS/成长型企业专项框架

#### **Rule of 40（40法则）**

**基础公式**：
```
Rule of 40 Score = 收入增长率% + EBITDA利润率% ≥ 40%
```

**阶段化标准**：
| ARR规模 | 增长策略 | 利润率容忍度 | 目标40法则 |
|---------|---------|-------------|-----------|
| <$5M | 市场占领 | -50%至-20% | 30-40%（增长为主） |
| $5M-$20M | 规模扩张 | -20%至0% | 35-45% |
| $20M-$50M | 效率优化 | 0%至15% | 40-50% |
| >$50M | 利润释放 | >15% | >40%（利润驱动） |

**加权Rule of 40（Weighted Rule of 40）**：
```
Weighted Score = (1.33 × 收入增长率) + (0.67 × EBITDA利润率)
```
- 更重视增长的质量评估方式
- >40%加权得分企业通常获得12-15x收入倍数

#### **资本效率指标**

**Burn Multiple（燃烧倍数）**：
```
Burn Multiple = 净现金消耗 / 净新增ARR
```

**评估标准**：
- **<1.0x**：优秀（每投入$1获得>$1新增ARR）
- **1.0-1.5x**：良好（Series A标准要求）
- **1.5-2.0x**：可接受（需改善趋势）
- **>2.5x**：危险（面临生存危机）

### 5.2 收入质量深度分析

**Net Revenue Retention（NRR，净收入留存率）**：
```
NRR = 期初ARR + 扩展收入 - 收缩收入 - 流失收入 / 期初ARR
```

**质量层级**：
- **>130%**：极佳（产品具有强扩展性，如Snowflake、Datadog）
- **110%-130%**：健康（正常扩张与流失平衡）
- **100%-110%**：警告（流失侵蚀增长）
- **<100%**：危险（产品与市场不匹配）

**CAC Payback（获客回收期）**：
```
CAC Payback = CAC / (ARR × 毛利率)
```

**健康标准**：
- **<12个月**：优秀
- **12-18个月**：可接受
- **>24个月**：需优化单位经济

### 5.3 传统成长性评估框架

**波特五力与行业增长**：
1. **现有竞争者**：集中度CR5、价格战强度
2. **新进入者威胁**：准入壁垒（牌照、资本、技术）
3. **替代品威胁**：技术颠覆风险（如AI对传统软件）
4. **买方议价能力**：客户集中度、转换成本
5. **供应商议价能力**：关键原料/技术依赖度

**SWOT与增长可持续性**：
- **优势（S）**：护城河类型（品牌、网络效应、切换成本、规模经济）
- **机会（O）**：TAM（可触达市场）、渗透率提升空间
- **风险（W/T）**：技术迭代、监管变化、宏观经济敏感度

## 六、综合估值与报告规范格式

### 6.1 估值结果汇总表（足球场图/Football Field）

```
估值方法                  低估值        中估值        高估值
─────────────────────────────────────────────────────────────
DCF（基础情景）             $X-10%        $X           $X+10%
DCF（WACC 8%-10%）          $Y            $Z           $W

─────────────────────────────────────────────────────────────
综合估值区间               $Low          $Mid         $High
当前市价/交易价            $Market
潜在涨跌幅                 -5%           +15%         +30%
```

### 6.2 专业估值报告标准结构

#### **1. 执行摘要（Executive Summary）**
- **估值结论**：明确的价值区间（如$1.2B-$1.5B）
- **核心假设**：3-5个最关键驱动因素
- **投资亮点**：3个买入理由 + 2个主要风险
- **一页纸限制**，供高管快速决策

#### **2. 投资逻辑（Investment Thesis）**
- **催化剂时间表**：未来6-12个月关键事件
- **差异化优势**：vs. 主要竞争对手
- **退出路径**：IPO、战略收购、PE secondary

#### **3. 公司概况（Business Description）**
- **历史沿革**：成立时间、里程碑、股权结构
- **商业模式**：收入流分解（产品线、区域、客户类型）
- **管理团队**：关键人风险与激励 alignment

#### **4. 行业分析（Industry Analysis）**
- **市场规模**：TAM/SAM/SOM数据及来源
- **竞争格局**：市场份额、竞争对手矩阵
- **趋势与监管**：技术变革、政策影响

#### **5. 财务分析（Financial Analysis）**
- **历史表现**：3-5年收入、利润、现金流趋势
- **比率分析**：盈利能力、运营效率、杠杆水平
- **与同业对比**：Gap分析及原因

#### **6. 估值分析（Valuation）**
- **DCF详细过程**：分阶段现金流、WACC计算、终值假设
- **可比公司表**：完整Comps表格及筛选逻辑
- **敏感性分析**：双变量矩阵
- **估值结论**：加权平均（DCF 50% + Comps 30% + Precedent 20%）

#### **7. 风险评估（Risk Factors）**
分类别阐述：
- **公司特定风险**：客户集中、关键人依赖、知识产权
- **行业风险**：竞争加剧、技术颠覆、监管收紧
- **宏观风险**：利率敏感度、汇率风险、经济周期
- **ESG风险**：碳足迹、治理结构、社会责任

#### **8. 附录（Appendix）**
- 完整三张表模型（IS/BS/CF）
- 可比公司财务数据明细
- 术语表与数据溯源

### 6.3 格式与呈现规范

**视觉标准**：
- **颜色编码**：深蓝（公司数据）、灰色（行业平均）、绿色（优于平均）、红色（劣于平均）
- **图表类型**：瀑布图（价值构成）、雷达图（竞争对比）、趋势图（5年收入增长）
- **页数控制**：初次覆盖50-100页，季报更新10-15页，快讯1-2页

**合规要求**：
- **披露声明**：研究限制、利益冲突、评级定义
- **数据来源**：明确标注SEC EDGAR、Capital IQ、Bloomberg等
- **估值日期**：所有价值锚定具体日期

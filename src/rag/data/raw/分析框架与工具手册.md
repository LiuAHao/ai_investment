# 分析框架与工具手册

## 适用范围

本手册面向 Agent 工具选择与常见问题分析，说明何时使用行情工具、新闻工具、知识工具，并提供常见投资问题的标准分析方法。

## 工具选择指南

| 场景 | 推荐工具 | 说明 |
|------|---------|------|
| 查询实时/历史价格 | 行情工具（cn_stock_history、cn_stock_spot_search） | 获取 K 线、成交量、最新价 |
| 查询公司动态、事件、公告 | 新闻工具（asset_news_search） | 获取新闻、公告、舆情 |
| 查询合规规则、指标口径、分析框架 | 知识工具（investment_framework_search） | 从知识库检索差异化内容 |
| 需要结合基本面+行情+新闻 | 综合链路 | 数据→新闻→知识→分析 |

## 常见问题标准分析方法

- "这只股票能买吗"：先查合规红线，再给数据与风险提示，不给确定性建议
- "财务指标怎么算"：查指标口径说明库
- "市场环境怎么样"：行情 + 新闻两路调研（MarketAgent + NewsAgent）
- "分析具体个股"：行情 + 新闻 + 知识三路调研
- "风险是什么"：查合规风控规则库

## 投资分析框架

1. 自上而下：宏观 → 行业 → 个股
2. 自下而上：个股基本面 → 行业景气 → 宏观验证
3. 多维度交叉验证：行情数据 + 新闻舆情 + 知识框架

## 沉淀经验写法（L3）

- 每条沉淀记录需注明 query、结论、证据来源、时间
- 复用知识：下次同类型问题可先检索沉淀知识再分析

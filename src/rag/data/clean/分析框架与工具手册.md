# 分析框架与工具手册

## 适用范围

本手册面向 Agent 工具选择与常见问题分析，说明何时使用行情工具、新闻工具、知识工具，并提供常见投资问题的标准分析方法。

## 工具选择指南

| 场景 | 推荐工具 | 说明 |
|------|---------|------|
| 查询实时/历史价格 | 行情工具（cn_stock_history、cn_stock_spot_search） | 获取 K 线、成交量、最新价 |
| 查询公司动态、事件、公告 | 新闻工具（asset_news_search） | 获取新闻、公告、舆情 |
| 查询合规规则、指标口径、分析框架 | 知识工具（investment_framework_search） | 从知识库检索差异化内容 |
| 查询基金资料/净值 | 基金工具（fund_profile、fund_nav） | 覆盖场内外基金 |
| 查询 ETF 详情/跟踪指数 | ETF 工具（etf_profile、etf_tracking） | 含 ETF 与标的指数关系 |
| 查询美股行情 | 美股工具（us_stock_quote、us_stock_history） | 美股主数据源为 AKShare |
| 解析用户提到的资产 | 资产工具（asset_resolve） | 先把名称/代码解析为标准化资产 |
| 需要结合基本面+行情+新闻 | 综合链路 | 数据→新闻→知识→分析 |

## 常见问题标准分析方法

- "这只股票能买吗"：先查合规红线，再给数据与风险提示，不给确定性建议
- "财务指标怎么算"：查指标口径说明库（优先 TTM 口径）
- "市场环境怎么样"：行情 + 新闻两路调研（MarketAgent + NewsAgent）
- "分析具体个股"：行情 + 新闻 + 知识三路调研
- "风险是什么"：查合规风控规则库
- "某公司估值贵不贵"：先取 PE/PB/PS 等估值指标，再结合行业属性判断适用方法（见下）

## 估值方法适用场景

| 估值方法 | 核心公式 | 适用场景 | 不适用/注意 |
|---------|---------|---------|------------|
| PE（市盈率） | 市值 ÷ 净利润 | 盈利稳定的成熟行业（消费、白酒、银行） | 亏损或微利企业 PE 无意义；强周期股盈利顶点时 PE 低反而是危险信号 |
| PB（市净率） | 市值 ÷ 净资产 | 重资产行业（银行、保险、券商、地产） | 轻资产公司（软件、互联网）净资产参考意义弱 |
| PS（市销率） | 市值 ÷ 营业收入 | 尚未盈利的成长股、互联网/SAAS | 需关注收入质量与增长可持续性 |
| PEG | PE ÷ 盈利增长率 | 成长股横向比较 | 增长率口径需统一，PEG<1 常视为低估 |
| EV/EBITDA | （市值+净债务）÷ EBITDA | 重资产、高折旧行业（制造、公用事业） | 需掌握完整债务数据，跨市场注意口径 |
| DCF（现金流折现） | 未来自由现金流折现之和 | 现金流可预测的成熟公司 | 对假设高度敏感，A股工具覆盖有限，作为思维框架而非精确计算 |
| PCE/PCF（市现率） | 市值 ÷ 经营/自由现金流 | 现金流稳定企业 | 需关注现金流质量与资本开支强度 |

**快速判断口诀**：盈利看 PE、资产看 PB、成长看 PEG、收入看 PS、现金流看 PCF、跨杠杆折旧看 EV/EBITDA。

## 投资分析框架

1. 自上而下：宏观 → 行业 → 个股
2. 自下而上：个股基本面 → 行业景气 → 宏观验证
3. 多维度交叉验证：行情数据 + 新闻舆情 + 知识框架
4. 基本面四维分析：
   - 盈利能力：ROE、净利率、毛利率趋势
   - 成长能力：营收/净利润增速及持续性
   - 财务健康：资产负债率、现金流覆盖、商誉占比
   - 估值水平：PE/PB/PS 与自身历史及同行对比

## 工具使用边界与降级

- cn_stock_history 支持 A股/指数/场内 ETF；美股与场外基金需用 us_stock_*/fund_* 工具
- 数据源优先级：Tushare（有权限时）> AKShare 东财 > 腾讯 > 新浪；tushare 无权限字段自动回退 AKShare
- 行情失败时回退：cn_stock_history → cn_stock_spot_search（实时行情兜底）
- 基金数据：fund_profile/fund_nav 优先 Tushare，失败回退 AKShare 天天基金
- 美股：Tushare us_daily 无权限时自动回退 AKShare（stock_us_spot_em / stock_us_daily）
- 新闻：AKShare 为兜底源，覆盖 A股/港股/美股/ETF/基金/行业
- 任何工具失败需在回答中说明数据缺失，避免用幻觉数据补全

## 沉淀经验写法（L3）

- 每条沉淀记录需注明 query、结论、证据来源、时间
- 复用知识：下次同类型问题可先检索沉淀知识再分析
- 沉淀内容优先为"可复用方法/口径/规则"，而非时效性结论（由质量管控管线蒸馏）

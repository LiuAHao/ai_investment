## 一、技术分析概述

### 1.1 定义与核心假设

技术分析是通过研究市场历史数据（主要是价格和成交量）来预测未来价格走势的方法。其理论基础基于三个核心假设：

| 假设 | 说明 |
|------|------|
| **市场行为包容消化一切** | 所有影响价格的因素（基本面、政治、心理等）都反映在价格走势中 |
| **价格以趋势方式演变** | 价格变动具有惯性，趋势一旦形成会持续一段时间 |
| **历史会重演** | 市场参与者的心理和行为模式具有重复性 |

### 1.2 技术分析 vs 基本面分析

| 维度 | 技术分析 | 基本面分析 |
|------|----------|------------|
| **研究对象** | 价格、成交量、图表形态 | 公司财务、行业前景、宏观经济 |
| **时间框架** | 短期、中期 | 中长期 |
| **核心逻辑** | 供需关系、市场情绪 | 内在价值、成长性 |
| **优势** | 反应迅速、适用范围广 | 把握价值、安全边际 |

## 二、移动平均线（MA）

### 2.1 基本概念

移动平均线（Moving Average, MA）是将某段时间内的收盘价相加后除以天数，形成的一条平滑曲线，用于消除价格随机波动，显示价格趋势方向。

### 2.2 计算公式

**简单移动平均线（SMA）：**
$$MA_n = \frac{C_1 + C_2 + \cdots + C_n}{n} = \frac{\sum_{i=1}^{n} C_i}{n}$$

其中，$C_i$为第$i$日的收盘价，$n$为计算周期。

**指数移动平均线（EMA）：**
$$EMA_t = \alpha \times C_t + (1-\alpha) \times EMA_{t-1}$$

其中，$\alpha = \frac{2}{n+1}$为平滑系数，$EMA$对近期价格赋予更高权重。

### 2.3 常用周期分类

| 类型 | 周期 | 用途 |
|------|------|------|
| **短期均线** | 5日、10日 | 捕捉短期趋势，适合日内/短线交易 |
| **中期均线** | 20日、30日、60日 | 判断中期趋势，月线级别参考 |
| **长期均线** | 120日、250日 | 判断长期趋势，牛熊分界线 |

> **特殊命名：**
> - MA5：周线（一周5个交易日）
> - MA20：月线（一月约20个交易日）
> - MA60：季线
> - MA120：半年线
> - MA250：年线

### 2.4 均线应用法则

#### 2.4.1 葛兰碧八大法则（Granville's Rules）

```
买入信号（4个）：
1. 均线由下降转平，价格向上突破均线
2. 价格位于均线之上，回调未跌破均线再度上升
3. 价格跌破均线，但均线仍向上，价格迅速回到均线上方
4. 价格暴跌远离均线，乖离率过大，可能反弹

卖出信号（4个）：
5. 均线由上升转平，价格向下跌破均线
6. 价格位于均线之下，反弹未突破均线再度下跌
7. 价格突破均线，但均线仍向下，价格迅速回到均线下方
8. 价格暴涨远离均线，乖离率过大，可能回调
```

#### 2.4.2 均线排列形态

| 形态 | 特征 | 市场含义 |
|------|------|----------|
| **多头排列** | 短期>中期>长期，全部向上 | 强势上涨，宜持股待涨 |
| **空头排列** | 短期<中期<长期，全部向下 | 弱势下跌，宜空仓观望 |
| **均线粘合** | 多条均线纠缠在一起 | 变盘信号，关注突破方向 |
| **均线发散** | 各均线间距扩大 | 趋势加速，注意乖离风险 |

#### 2.4.3 金叉与死叉

- **金叉（Golden Cross）**：短期均线上穿长期均线，买入信号
 - 典型案例：MA5上穿MA10（短线金叉），MA50上穿MA200（长线金叉）
 
- **死叉（Death Cross）**：短期均线下穿长期均线，卖出信号

**有效性判断：**
- 长期均线方向向上时的金叉更可靠
- 成交量配合可提升信号可信度
- 周期越长，信号越滞后但越可靠

### 2.5 乖离率（BIAS）

衡量价格与均线的偏离程度：

$$BIAS = \frac{C_t - MA_n}{MA_n} \times 100\%$$

**应用参考：**
- 个股BIAS > +5%：可能超买，考虑减仓
- 个股BIAS < -5%：可能超卖，考虑低吸
- 大盘BIAS阈值通常小于个股

## 三、MACD指标

### 3.1 基本概念

MACD（Moving Average Convergence Divergence，指数平滑异同移动平均线）由Gerald Appel于1970年代提出，是趋势跟踪型动量指标，用于判断价格趋势的方向、强度和反转信号。

### 3.2 计算公式

**第一步：计算EMA**
- $EMA_{12} = \frac{11}{13} \times EMA_{12,t-1} + \frac{2}{13} \times C_t$
- $EMA_{26} = \frac{25}{27} \times EMA_{26,t-1} + \frac{2}{27} \times C_t$

**第二步：计算DIF（差离值）**
$$DIF = EMA_{12} - EMA_{26}$$

**第三步：计算DEA（信号线/慢线）**
$$DEA = \frac{8}{10} \times DEA_{t-1} + \frac{2}{10} \times DIF$$

**第四步：计算MACD柱状图（BAR/OSC）**
$$BAR = 2 \times (DIF - DEA)$$

### 3.3 指标构成要素

| 要素 | 名称 | 作用 |
|------|------|------|
| DIF线 | 快线 | 反映短期趋势变化 |
| DEA线 | 慢线/信号线 | 反映中期趋势，作为DIF的平滑 |
| 零轴 | 多空分界线 | DIF/DEA在零轴上方为多头市场 |
| 柱状图 | MACD柱 | 显示DIF与DEA的差值，代表动能 |

### 3.4 主要应用法则

#### 3.4.1 金叉与死叉

**DIF与DEA金叉：**
- **零轴上金叉**：强势回调结束，加仓信号（最佳买点）
- **零轴下金叉**：弱势反弹，可能是下跌中继，谨慎参与

**DIF与DEA死叉：**
- **零轴上死叉**：短期回调，减仓信号
- **零轴下死叉**：空头延续，持币观望

#### 3.4.2 背离分析（Divergence）

背离是MACD最可靠的信号之一，分为顶背离和底背离：

**顶背离（Bearish Divergence）：**
```
价格走势：高点抬升（Higher High）
MACD走势：高点降低（Lower High）
含义：上涨动能减弱，可能见顶
操作：减仓或清仓，警惕反转
```

**底背离（Bullish Divergence）：**
```
价格走势：低点降低（Lower Low）
MACD走势：低点抬升（Higher Low）
含义：下跌动能减弱，可能见底
操作：关注企稳信号，准备建仓
```

**背离有效性条件：**
- 需经过连续两次以上背离确认
- 结合成交量变化验证
- 大周期（周线、月线）背离更可靠

#### 3.4.3 柱状图分析

| 柱状图状态 | 市场含义 |
|------------|----------|
| 红柱放大 | 多头动能增强 |
| 红柱缩小 | 多头动能减弱，可能回调 |
| 绿柱放大 | 空头动能增强 |
| 绿柱缩小 | 空头动能减弱，可能反弹 |
| 缩头抽脚 | 红/绿柱缩短，趋势可能转折 |

### 3.5 MACD的局限性

1. **滞后性**：基于均线计算，信号出现晚于价格变动
2. **盘整失效**：震荡行情中频繁发出假信号
3. **极端行情**：暴涨暴跌时指标可能钝化
4. **建议**：结合KDJ、成交量等其他指标综合判断

## 四、KDJ指标

### 4.1 基本概念

KDJ（随机指标，Stochastic Oscillator）由George Lane提出，是摆动类指标，通过比较收盘价与一定周期内价格波动的关系，判断超买超卖状态，特别适合震荡行情和短期转折点捕捉。

### 4.2 计算公式

**第一步：计算未成熟随机值（RSV）**
$$RSV_n = \frac{C_t - L_n}{H_n - L_n} \times 100$$

其中，$C_t$为当日收盘价，$L_n$为$n$日内最低价，$H_n$为$n$日内最高价，通常$n=9$。

**第二步：计算K值（快线）**
$$K_t = \frac{2}{3} \times K_{t-1} + \frac{1}{3} \times RSV_t$$

**第三步：计算D值（慢线）**
$$D_t = \frac{2}{3} \times D_{t-1} + \frac{1}{3} \times K_t$$

**第四步：计算J值（方向敏感线）**
$$J = 3K - 2D$$

### 4.3 指标参数设置

| 参数 | 默认值 | 调整建议 |
|------|--------|----------|
| N（周期） | 9 | 短线可设为5，长线可设为21 |
| M1（K平滑） | 3 | 通常保持不变 |
| M2（D平滑） | 3 | 通常保持不变 |

### 4.4 主要应用法则

#### 4.4.1 超买超卖区域

| 区域 | K值范围 | 市场含义 | 操作建议 |
|------|---------|----------|----------|
| 超买区 | K > 80 | 买方力量过度 | 警惕回调，考虑减仓 |
| 超卖区 | K < 20 | 卖方力量过度 | 关注反弹，准备低吸 |
| 徘徊区 | 20-80 | 多空平衡 | 观望或趋势跟踪 |

> **注意**：在极强趋势中，KDJ可能在超买/超卖区持续运行，此时应顺势操作而非逆势。

#### 4.4.2 金叉与死叉

**KDJ金叉：**
- **低位金叉**（20以下）：可靠性高，买入信号
- **中位金叉**：趋势延续信号
- **高位金叉**（80以上）：谨慎追涨，可能诱多

**KDJ死叉：**
- **高位死叉**（80以上）：可靠性高，卖出信号
- **中位死叉**：短期调整信号
- **低位死叉**（20以下）：可能是空头陷阱

#### 4.4.3 J值的特殊应用

J值是KDJ中最敏感的线，波动范围可超过0-100：

| J值状态 | 市场含义 |
|---------|----------|
| J > 100 | 严重超买，通常维持数日即回调 |
| J < 0 | 严重超卖，通常维持数日即反弹 |
| J与K、D背离 | 预警信号，关注趋势转折 |

#### 4.4.4 背离分析

与MACD类似，KDJ也存在背离现象：

- **顶背离**：价格新高，KDJ未新高 → 卖出信号
- **底背离**：价格新低，KDJ未新低 → 买入信号

**KDJ背离的特点：**
- 反应比MACD更灵敏，适合短期操作
- 需结合价格形态确认（如头肩顶、双底）
- 多周期共振时可靠性最高

### 4.5 KDJ与MACD的配合使用

| 市场环境 | MACD | KDJ | 操作策略 |
|----------|------|-----|----------|
| 上升趋势 | 零轴上金叉 | 50附近金叉 | 强势加仓 |
| 下降趋势 | 零轴下死叉 | 50附近死叉 | 持币观望 |
| 震荡整理 | 粘合 | 超买超卖区摆动 | 高抛低吸 |
| 趋势转折 | 背离 | 背离 | 确认后反向操作 |

## 五、成交量分析

### 5.1 基本概念

成交量（Volume）是技术分析的基础要素，反映市场参与度和资金流向。道氏理论强调"成交量验证价格趋势"，是判断趋势强度和真实性的关键指标。

### 5.2 成交量的类型与形态

#### 5.2.1 量价关系基本法则

| 量价组合 | 名称 | 市场含义 |
|----------|------|----------|
| 价涨量增 | 量增价涨 | 上涨动能充足，趋势健康 |
| 价涨量缩 | 量缩价涨 | 上涨乏力，可能背离 |
| 价跌量增 | 量增价跌 | 恐慌抛售，可能见底 |
| 价跌量缩 | 量缩价跌 | 抛压减轻，可能企稳 |
| 价平量增 | 量增价平 | 多空分歧，变盘前兆 |
| 价平量缩 | 地量地价 | 市场清淡，底部特征 |

#### 5.2.2 特殊成交量形态

**天量与地量：**
- **天量**：成交量创近期新高，通常伴随重要转折
 - 高位天量：主力出货，警惕见顶
 - 低位天量：资金介入，可能启动
 
- **地量**：成交量创近期新低，市场低迷
 - 地量地价：底部区域，等待放量确认
 - 上涨中继地量：洗盘结束，关注突破

**堆量：**
成交量持续温和放大，呈阶梯状上升，通常是主力建仓或健康上涨的特征。

**缩量横盘：**
价格波动收窄，成交量萎缩，代表洗盘或蓄势，关注突破方向。

### 5.3 成交量指标

#### 5.3.1 均量线（MV）

与移动平均线类似，计算成交量的平均值：

- **MV5、MV10**：短期均量线，判断短期量能变化
- **MV60**：中期均量线，判断资金趋势

**应用：**
- 成交量突破均量线：资金活跃度提升
- 均量线金叉：量能趋势向好
- 量价配合：价格上涨+成交量>MV，趋势可靠

#### 5.3.2 量比

$$量比 = \frac{当日即时成交量}{过去5日平均每分钟成交量}$$

| 量比范围 | 市场含义 |
|----------|----------|
| 0.8-1.5 | 正常水平 |
| 1.5-2.5 | 温和放量 |
| 2.5-5 | 明显放量 |
| 5-10 | 剧烈放量 |
| >10 | 极端放量 |

#### 5.3.3 换手率

$$换手率 = \frac{当日成交量}{流通股本} \times 100\%$$

| 换手率 | 市场含义 |
|--------|----------|
| <1% | 极度低迷，冷门股 |
| 1%-3% | 正常水平，关注不高 |
| 3%-7% | 相对活跃，有资金关注 |
| 7%-10% | 高度活跃，强势股特征 |
| >10% | 非常活跃，可能主力运作 |
| >20% | 异常活跃，警惕出货 |

### 5.4 量价分析实战要点

**上涨趋势中的量价验证：**
1. 启动期：温和放量，量价齐升
2. 主升浪：持续放量，偶尔缩量回调
3. 赶顶期：放量滞涨，天量天价

**下跌趋势中的量价特征：**
1. 初期：放量下跌，恐慌盘涌出
2. 中期：缩量阴跌，人气涣散
3. 末期：地量地价，极度低迷

## 六、趋势判断基础

### 6.1 趋势的定义与分类

**趋势定义**：价格运行的总体方向，由一系列连续的波峰和波谷构成。

| 趋势类型 | 定义 | 操作原则 |
|----------|------|----------|
| **上升趋势** | 波峰和波谷不断抬高 | 逢低做多，持有多单 |
| **下降趋势** | 波峰和波谷不断降低 | 逢高做空，持有空单 |
| **横向趋势** | 波峰波谷基本水平 | 高抛低吸，等待突破 |

### 6.2 趋势线与通道

#### 6.2.1 趋势线画法

**上升趋势线：**
- 连接两个以上低点，斜向上
- 第三点验证有效性
- 被有效跌破视为趋势转折

**下降趋势线：**
- 连接两个以上高点，斜向下
- 第三点验证有效性
- 被有效突破视为趋势转折

**有效性标准：**
- 触及次数越多，趋势线越重要
- 时间跨度越长，趋势线越有效
- 突破需满足3%原则或连续三日原则

#### 6.2.2 趋势通道

由两条平行的趋势线构成：

```
上升通道：上升趋势线 + 平行于趋势线的上轨
下降通道：下降趋势线 + 平行于趋势线的下轨
```

**通道应用：**
- 通道下轨：支撑位，买入参考
- 通道上轨：压力位，卖出参考
- 通道突破：可能开启新趋势

### 6.3 支撑与阻力

| 概念 | 定义 | 形成原因 |
|------|------|----------|
| **支撑位** | 价格下跌时可能止跌的价位 | 前期低点、成交密集区、心理关口 |
| **阻力位** | 价格上涨时可能遇阻的价位 | 前期高点、成交密集区、整数关口 |

**支撑阻力转换：**
- 支撑被跌破后，转为后期上涨的阻力
- 阻力被突破后，转为后期回调的支撑

**关键位识别：**
1. 前期高低点
2. 趋势线与通道线
3. 均线系统（特别是MA60、MA250）
4. 黄金分割位（0.382、0.5、0.618）
5. 整数关口（如3000点、100元）

### 6.4 趋势阶段理论（道氏理论）

| 阶段 | 特征 | 操作重点 |
|------|------|----------|
| **积累阶段** | 底部区域，成交量萎缩，价格波动小 | 长线建仓，耐心持有 |
| **上升阶段** | 趋势确立，量价齐升，回调有限 | 顺势加仓，利用回调买入 |
| **派发阶段** | 高位震荡，放量滞涨，分歧加大 | 逐步减仓，不再追高 |
| **下降阶段** | 趋势逆转，下跌加速，恐慌蔓延 | 空仓观望，等待机会 |

### 6.5 多周期分析

**时间周期层级：**

```
长期趋势（年线、月线）→ 判断牛熊，决定战略方向
中期趋势（周线、日线）→ 判断波段，决定战术布局 
短期趋势（60分钟、15分钟）→ 判断时机，决定具体买卖点
```

**周期关系：**
- 大周期决定小周期，小周期服从大周期
- 多周期共振时，信号最可靠
- 大周期向上时，小周期回调是买入机会

## 七、综合应用与实战要点

### 7.1 多指标共振系统

**买入信号共振（多指标同时发出买入信号）：**

| 条件 | 具体要求 | 权重 |
|------|----------|------|
| 趋势判断 | 价格在MA60上方，均线多头排列 | ★★★ |
| MACD | 零轴上金叉，或底背离后金叉 | ★★★ |
| KDJ | 低位金叉（20以下），J值上穿0 | ★★ |
| 成交量 | 放量突破均量线，量比>1.5 | ★★★ |
| 形态 | 突破整理形态（三角形、箱体） | ★★ |

**卖出信号共振：**

- 价格跌破MA60，均线空头排列
- MACD零轴下死叉，或顶背离
- KDJ高位死叉（80以上）
- 放量滞涨或缩量下跌
- 跌破关键支撑位

### 7.2 不同市场环境下的策略

| 市场环境 | 特征 | 策略 | 重点指标 |
|----------|------|------|----------|
| **牛市** | 均线多头排列，MACD零轴上 | 持股为主，回调买入 | MA20支撑、MACD红柱 |
| **熊市** | 均线空头排列，MACD零轴下 | 空仓为主，反弹减仓 | MA10压力、KDJ超买区 |
| **震荡市** | 均线粘合，MACD零轴附近 | 高抛低吸，严格止损 | KDJ超买超卖、布林带 |
| **转折期** | 背离信号，成交量异常 | 减仓观望，等待确认 | 背离、成交量、趋势线 |

### 7.3 风险管理原则

1. **止损纪律**
 - 固定比例止损：亏损达本金的5%-8%止损
 - 技术位止损：跌破关键支撑/趋势线止损
 - 时间止损：持仓达预期时间未盈利即离场

2. **仓位管理**
 - 单次交易风险不超过总资金的2%
 - 趋势不明时仓位不超过30%
 - 盈利后可加仓，但不超过初始仓位的50%

3. **指标失效处理**
 - 连续两次信号失败，暂停使用该指标
 - 极端行情（涨停/跌停潮）放弃技术指标
 - 重大消息面前，技术让位于基本面

## 八、风险提示

### 8.1 技术分析的局限性

1. **概率性而非确定性**：技术分析基于历史规律，但市场不会简单重复
2. **自我实现与自我否定**：流行指标可能被主力利用制造陷阱
3. **黑天鹅事件**：突发消息可能使技术形态瞬间失效
4. **过度拟合风险**：复杂系统在历史数据上表现好，实战效果差

### 8.2 常见误区

| 误区 | 正确认知 |
|------|----------|
| 迷信单一指标 | 多指标验证，没有完美指标 |
| 忽视市场环境 | 牛市熊市策略不同，不能刻舟求剑 |
| 过度交易 | 等待高胜率机会，减少无效交易 |
| 重技术轻风控 | 止损比选股更重要 |
| 追求绝对顶部/底部 | 吃鱼身，放弃鱼头鱼尾 |

- 过往表现不代表未来收益
